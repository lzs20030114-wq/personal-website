> **AI 解析的 prompt 是 CTW 专属的**，不套用选择题那套。填词题（C-test）的考点是「前缀字母 + 句子语法形态 + 固定搭配 + 上下文衔接」，所以让模型先指出决定性线索（时态/单复数/词性/介词搭配），再说你填的那个词错在词形、搭配还是拼写；未作答则只讲怎么从前缀和语境推出来。
>
> **几个决策**：
> - 复用项目既有的四套 hook 模式（缓存在 localStorage + 点了才调 API + Pro gate），所以重复看同一题不重复计费，不点不花钱。
> - AI 块 Pro 专属（与现有阅读/BS 解析一致），但**面板前两层对所有人可见**——那是本地数据，零成本。
> - 定位句子必须靠 `position` 算，不能用 `sentence_index`：真题库那 116 条 CTW 的 blank 里**没有**这个字段（只有练习库有），依赖它真题页就会炸。已让子代理专门加一条测试覆盖真题形状。

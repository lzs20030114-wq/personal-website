### 助手

> **Lint 是代码检查工具！**
>
> 简单说就是：**帮你找代码里的小错误和不规范写法的助手。**
>
> ## **形象比喻：**
>
> 就像 Word 里的拼写检查：
> - Word 会给拼错的单词下面画红色波浪线 ~~~
> - Lint 会给不规范的代码画波浪线
> - 帮你在运行前就发现问题
>
> ## **Lint 能发现什么问题？**
>
> ```python
> # 1. 变量定义了但没用
> x = 10  # ← Lint 会提示："x 定义了但没使用"
> print("hello")
>
> # 2. 缩进不对
> def my_function():
> print("错了")  # ← Lint 会提示："缩进有问题"
>
> # 3. 导入了但没用
> import math  # ← Lint 会提示："导入了但没用到"
> print("hello")
>
> # 4. 代码风格不规范
> x=1+2  # ← Lint 建议：等号前后应该有空格 x = 1 + 2
> ```
>
> ## **为什么叫 Lint？**
>
> 这个名字来自 1970 年代，原意是"衣服上的绒毛/线头"，就像帮你清理代码里的小毛病。
>
> ## **常见的 Python Lint 工具：**
>
> 1. **Pylint** - 最严格
> 2. **Flake8** - 比较常用
> 3. **PyLint** - VS Code 内置
> 4. **Black** - 自动格式化代码
>
> ## **你在 VS Code 里看到的：**
>
> VS Code 里那些波浪线、黄色警告，很多就是 Lint 在工作：
> - 🔴 红色波浪线 = 语法错误（代码无法运行）
> - 🟡 黄色波浪线 = 警告（代码能跑，但不规范）
> - 💡 灯泡图标 = 建议改进
>
> ## **要不要管它？**
>
> **初学阶段：**
> - 红色错误必须改
> - 黄色警告可以先忽略
> - 等熟练了再关注代码规范
>
> **总结：Lint = 代码"体检医生"，帮你写出更干净的代码。**
>

> def hello(name,age):

> ```

> ```python
> def hello(name, age):
>     x = 10
>     if x > 5:

>     y = 20
>     return x + y
> ```

> ## **格式化做了什么？**
>
> 1. **统一缩进** - 该缩进的地方自动缩进

> 4. **对齐括号** - 让括号、引号对得整齐
> 5. **统一引号** - 比如都用双引号或单引号
>
> ## **为什么要格式化？**
>
> - **更容易阅读** - 自己看、别人看都舒服
> - **符合规范** - Python 有官方风格指南 PEP 8
> - **避免错误** - 缩进错误是 Python 常见 bug
> - **专业习惯** - 公司里都要求代码格式规范
>

### 助手

> **PEP 8 = Python 官方的代码风格指南**
>
> 就像"写作文要遵循语法规则"一样，Python 代码也有一套"书写规范"。
>
> ## **PEP 是什么？**
>
> **PEP = Python Enhancement Proposal**（Python 增强提案）
> - 就是 Python 社区的"官方文档"
> - 有很多个 PEP，编号从 1, 2, 3... 一直排下去
> - **PEP 8** 专门讲"代码应该怎么写才好看"
>
> ## **PEP 8 主要规定什么？**
>
> ### **1. 缩进**
> ```python
> # ✓ 正确：用 4 个空格缩进
> def hello():
>     print("hi")
>
> # ✗ 错误：用 2 个空格或 tab
> def hello():
>   print("hi")
> ```
>
> ### **2. 每行长度**
> ```python
> # ✓ 正确：每行不超过 79 个字符
> name = "Alice"
>
> # ✗ 错误：一行太长
> very_long_variable_name = "This is a very very very very very very very long string that goes on forever"
> ```
>
> ### **3. 空格**
> ```python
> # ✓ 正确：运算符前后有空格
> x = 1 + 2
> result = my_function(a, b)
>
> # ✗ 错误：挤在一起
> x=1+2
> result=my_function(a,b)
> ```
>
> ### **4. 空行**
> ```python
> # ✓ 正确：函数之间空两行
> def function1():
>     pass
>
>
> def function2():
>     pass
>
> # ✗ 错误：没有空行
> def function1():
>     pass
> def function2():
>     pass
> ```
>
> ### **5. 命名规则**
> ```python
> # ✓ 正确：变量和函数用小写+下划线
> user_name = "Alice"
> def calculate_total():
>     pass
>
> # ✓ 正确：类名用大写开头
> class MyClass:
>     pass
>
> # ✗ 错误：变量用大写
> UserName = "Alice"
> ```
>
> ### **6. 导入顺序**
> ```python
> # ✓ 正确：标准库 → 第三方库 → 自己的模块
> import os
> import sys
>
> import numpy
> import pandas
>
> import my_module
> ```
>
> ## **为什么要遵循 PEP 8？**
>
> 1. **团队协作** - 大家写的代码风格统一，容易看懂
> 2. **专业习惯** - 公司、开源项目都遵循这个标准
> 3. **更少 bug** - 规范的代码不容易出错
> 4. **面试加分** - 面试官会看你的代码规范
>
> ## **初学者需要背 PEP 8 吗？**
>
> **不需要！**
> - 用格式化工具（Black, autopep8）自动搞定
> - 写多了自然就习惯了
> - VS Code 的 Linter 会提醒你哪里不规范
>
> ## **类比理解：**
>
> 就像英文写作：
> - **语法错误** = 代码 bug（程序跑不起来）
> - **PEP 8** = 写作风格（程序能跑，但不够专业）
>
> 比如：
> - "I goes to school" - 语法错误
> - "i go to school" - 语法对但不规范（首字母应该大写）
>
> ## **你现在需要做什么？**
>
> **完全不用管 PEP 8！**
> - 先把代码写出来、跑起来
> - 装个格式化工具自动处理
> - 等熟练了自然就符合规范了
>
> ---
>
> **总结：PEP 8 = Python 的"写作规范"，但初学者不用刻意记，用工具自动处理就行。**

> ## **最简单的理解：**
>
> ```python

> name = 'Alice'
> name = "Alice"

> message = 'Hello World'
> message = "Hello World"
> ```
>
> **输出结果一模一样！**

> ---

> ## **那为什么要有两种？**
>
> ### **原因：方便你在字符串里包含引号**
>
> #### **情况1：文字里有单引号**
> ```python
> # ✓ 用双引号包起来
> sentence = "I'm a student"  # 文字里有 'm（单引号）
>
> # ✗ 如果用单引号会出错
> sentence = 'I'm a student'  # 报错！Python 以为在 I 后面就结束了
> ```
>
> #### **情况2：文字里有双引号**
> ```python
> # ✓ 用单引号包起来
> sentence = 'He said "Hello"'  # 文字里有双引号
>
> # ✗ 如果用双引号会出错
> sentence = "He said "Hello""  # 报错！
> ```
>
> ---
>
> ## **如果两种引号都要用怎么办？**
>
> ### **方法1：用转义符 `\`**
> ```python
> sentence = "I'm saying \"Hello\""
> # 输出：I'm saying "Hello"
>
> sentence = 'I\'m saying "Hello"'
> # 输出：I'm saying "Hello"
> ```
>
> ### **方法2：用三引号 `'''` 或 `"""`**
> ```python
> text = '''He said "I'm happy"'''
> # 或者
> text = """He said "I'm happy" """
> ```
>
> ---
>
> ## **Python 程序员的习惯：**
>
> ### **选一种，全程用它**
> ```python
> # 风格1：全部用单引号
> name = 'Alice'
> city = 'Beijing'
> message = 'Hello'
>
> # 风格2：全部用双引号
> name = "Alice"
> city = "Beijing"  
> message = "Hello"
> ```
>
> ### **哪个更常见？**
> - **单引号 `' '`** - Python 社区稍微更常用
> - **双引号 `" "`** - 其他语言（JavaScript、Java）更常用
> - **但真的随便，看个人喜好**
>
> ---
>
> ## **三引号是什么？**
>
> 用来写**多行文字**：
>
> ```python
> # 单行文字
> message = "Hello"
>
> # 多行文字
> long_text = """
> 这是第一行
> 这是第二行
> 这是第三行
> """
>
> poem = '''
> 床前明月光
> 疑是地上霜
> '''
> ```
>
> ---
>
> ## **总结：**

> | 符号 | 用途 | 例子 |
> |------|------|------|
> | `'...'` | 单行文字 | `'Hello'` |
> | `"..."` | 单行文字 | `"Hello"` |
> | `'''...'''` | 多行文字 | `'''第一行\n第二行'''` |
> | `"""..."""` | 多行文字/注释 | `"""这是注释"""` |

### 助手

> **Floating number = 浮点数 = 带小数点的数字**
>
> ## **简单理解：**
>
> ### **整数（Integer）**
> ```python
> x = 10
> y = 100
> z = -5
> ```
> 没有小数点的完整数字。
>
> ### **浮点数（Floating-point number / Float）**
> ```python
> x = 10.5
> y = 3.14
> z = -2.7
> price = 99.99
> ```
> **有小数点的数字。**
>
> ---
>
> ## **为什么叫 "Floating"（浮动）？**
>
> 因为小数点的位置可以"浮动"：
>
> ```python
> # 这些都是浮点数
> 123.45    # 小数点在中间
> 0.00123   # 小数点在前面
> 12345.0   # 小数点在后面
> ```
>
> 小数点可以在任何位置 → 所以叫"浮动的点" → Floating point
>
> ---
>
> ## **在 Python 里的区别：**
>
> ```python
> # 整数
> a = 10
> print(type(a))  # 输出：<class 'int'>
>
> # 浮点数
> b = 10.0
> print(type(b))  # 输出：<class 'float'>
>
> # 注意：即使是 10.0，只要有小数点就是浮点数
> ```
>
> ---
>
> ## **运算时的区别：**
>
> ### **整数运算**
> ```python
> x = 10
> y = 3
> print(x / y)  # 输出：3.3333333333333335（结果自动变浮点数）
> print(x // y) # 输出：3（整除，结果是整数）
> ```
>
> ### **浮点数运算**
> ```python
> x = 10.5
> y = 2.0
> print(x + y)  # 输出：12.5
> print(x * y)  # 输出：21.0
> ```
>
> ---
>
> ## **常见场景：**
>
> ### **需要用浮点数的情况：**
> ```python
> # 价格
> price = 19.99
>
> # 温度
> temperature = 36.5
>
> # 百分比
> percentage = 0.85
>
> # 科学计算
> pi = 3.14159
> ```
>
> ### **用整数就够的情况：**
> ```python
> # 年龄
> age = 25
>
> # 数量
> count = 100
>
> # 排名
> rank = 1
> ```
>
> ---
>
> ## **⚠️ 浮点数的小坑：**
>
> 浮点数有时不够精确：
>
> ```python
> # 看起来奇怪的结果
> print(0.1 + 0.2)  # 输出：0.30000000000000004（不是 0.3！）
>
> # 这是计算机存储小数的方式导致的
> # 对大多数情况影响不大
> ```
>
> **解决方法：**
> ```python
> # 方法1：四舍五入
> result = round(0.1 + 0.2, 2)  # 输出：0.3
>
> # 方法2：用 Decimal（处理钱的时候）
> from decimal import Decimal
> x = Decimal('0.1') + Decimal('0.2')  # 精确的 0.3
> ```
>
> ---
>
> ## **总结对比：**
>
> | 类型 | 英文 | 例子 | 用途 |
> |------|------|------|------|
> | 整数 | Integer / Int | `10, -5, 0` | 计数、索引 |
> | 浮点数 | Float / Floating-point | `10.5, 3.14, -2.7` | 价格、测量值 |
>
> ---
>
> ## **Python 里的写法：**
>
> ```python

> x = 10
>
> # 这些都是浮点数
> y = 10.0    # 有小数点

> w = .5      # 前面的0可以省略（0.5）
> a = 1e3     # 科学计数法：1×10³ = 1000.0
> ```

> ```
>
> - `students_count` = 盒子的标签（变量名）

>

> x = 20
> print(x)  # 输出：20
>

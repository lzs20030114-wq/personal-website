# 待确认主题｜三种括号的作用

### 用户

> 三种括号分别有什么作用

### 助手

> Python 中三种括号各有不同的用途：
>
> **圆括号 `()`**
> - 调用函数：`print("hello")`、`len(my_list)`
> - 定义函数参数：`def calculate(width, height):`
> - 创建元组（tuple）：`point = (3, 5)`
> - 控制运算优先级：`(2 + 3) * 4`
>
> **方括号 `[]`**
> - 创建列表（list）：`rooms = ["客厅", "卧室", "厨房"]`
> - 索引取值：`rooms[0]` 得到 "客厅"
> - 切片：`rooms[0:2]` 得到前两个元素
> - 访问字典的值：`floor_areas["客厅"]`
>
> **花括号 `{}`**
> - 创建字典（dict）：`floor_areas = {"客厅": 35, "卧室": 20}`
> - 创建集合（set）：`materials = {"木", "石", "玻璃"}`
> - 字符串格式化：`f"面积是 {area} 平方米"`
>
> 一个记忆技巧：方括号像一排格子，用来装有序的东西（列表）或者按位置取东西；花括号像一个容器，装的是键值对（字典）或不重复的元素（集合）；圆括号最通用，函数调用和元组都用它。
>
> 你现在学到 list、set、tuple 这些数据结构了，正好会频繁接触这三种括号的区别。有什么具体的例子想讨论吗？

### 用户

> tuple list set 分别有什么特点

### 助手

> 这三种数据结构的核心区别：
>
> **List 列表 `[]`**
> - **可变**：可以增删改元素
> - **有序**：元素有固定位置，可以用索引访问
> - **允许重复**
>
> ```python
> rooms = ["客厅", "卧室", "卧室"]  # 可以有重复
> rooms.append("厨房")              # 可以添加
> rooms[0] = "大厅"                 # 可以修改
> ```
>
> **Tuple 元组 `()`**
> - **不可变**：创建后不能修改
> - **有序**：可以用索引访问
> - **允许重复**
>
> ```python
> point = (3, 5)      # 一个坐标点
> x = point[0]        # 可以读取
> point[0] = 10       # ❌ 报错，不能修改
> ```
>
> **Set 集合 `{}`**
> - **可变**：可以增删元素
> - **无序**：没有索引，不能用位置访问
> - **不允许重复**：自动去重
>
> ```python
> materials = {"木", "石", "木"}  # 自动去重，实际只有两个
> materials.add("玻璃")           # 可以添加
> materials[0]                    # ❌ 报错，不能用索引
> ```
>
> ---
>
> **怎么选择用哪个？**
>
> | 场景 | 选择 | 例子 |
> |------|------|------|
> | 需要经常修改内容 | list | 施工进度清单 |
> | 数据不应该被改动 | tuple | 坐标点、RGB颜色值 |
> | 需要去重或判断存在 | set | 项目用到的所有材料种类 |
>
> 一个设计相关的例子：如果你要记录一个房间用了哪些材料，用 set 最合适，因为你只关心"用了什么"而不关心顺序，而且自动去重。但如果你要记录施工步骤的顺序，就得用 list。

### 用户

> .get是干啥用的

### 助手

> `.get()` 是**字典（dict）专用的取值方法**，比直接用方括号更安全。
>
> **对比一下：**
>
> ```python
> student = {"name": "小明", "age": 20}
>
> # 方括号取值
> student["name"]      # ✅ 得到 "小明"
> student["grade"]     # ❌ 报错 KeyError，因为键不存在
>
> # .get() 取值
> student.get("name")   # ✅ 得到 "小明"
> student.get("grade")  # ✅ 返回 None，不报错
> ```
>
> **还能设置默认值：**
>
> ```python
> student.get("grade", "未知")  # 键不存在时返回 "未知" 而不是 None
> ```
>
> ---
>
> **什么时候用哪个？**
>
> - 确定键一定存在 → 用 `dict["key"]`
> - 不确定键存不存在 → 用 `dict.get("key")`
>
> 设计相关的例子：假如你有一个存储房间信息的字典，有些房间可能没填面积数据，用 `.get()` 就不会因为缺数据而让程序崩掉。
>
> ```python
> room = {"name": "卧室", "area": 20}
> height = room.get("height", 2.8)  # 没填层高就默认 2.8 米
> ```

# 智能床与睡眠研究｜智慧睡眠项目工作总结与研究生选校分析

### 用户

> 总结我这个project的工作 以供我拿去做未来研究生选校分析

### 助手

> 这个 project 是清华未来实验室触觉团队与慕思（Derucci）合作的「2030智慧睡眠前瞻研究」，定位是面向 2030 的智慧睡眠产品概念前瞻，方法上由文献综述、用户研究、设计产出三块构成。你在其中负责人群需求线，具体是第3章 3.3「未来典型睡眠人群假设」，同时承担了全队问卷工作的统筹与方法把关角色。
>
> 你实际的产出有几块。最核心的是 3.3 的四类未来睡眠人群分类框架——以「该人群是否已被主流话语充分讨论」为分类轴，划出需求放大型、需求转向型、需求显现型、需求稳定型四类。这不是一张人群清单，而是一个有明确分类逻辑的概念框架，是整段工作的智识内核。围绕它你完成了 3.3 全文与配套学术图，并在过程中坚持了相当严的引用规范（DOI 核验、不臆造文献、关键文献作者全列、企业自报数据在正文中明确降级）。方法层面，你制定了全队问卷的设计规范（10 条硬规则），并独立完成了 G 部分全套题目（G1–G8），核心是一个很锋利的研究张力——「克制的智能」：主动陪伴 vs. 无感的家具。此外你也参与了第5章七个市场缺口框架的搭建，那是从研究通向概念设计的桥梁。
>
> 把这些往计算设计方向上映射，能直接支撑你的是几项能力：研究方法与学术严谨度（建分类、控引用、框架化思维）、实证用户研究（问卷设计与测量）、面向未来的思辨设计（2030 前瞻），以及系统与交互层面的思考——「克制的智能」这个张力、把睡眠从单人行为重构为「家庭夜间生活系统」的视角，本质上都是 HCI / 交互设计的问题，七个市场缺口也把睡眠重新框成关系性、生态级的命题。再加上产学合作、应用型研究的背景，这是一份扎实的「设计研究 + 问题框定」证据。
>
> 需要对自己诚实的是缺口：这个 project 到目前为止是研究和概念驱动的，没有计算/编程成分，没有数据分析管线，也还没有落地原型（下游概念设计还在路上）。对偏技术的计算设计项目（参数化/生成式、机器学习驱动、把数据当材料那一类），这段经历能撑起「设计研究 + 问题框定」的一半，但撑不起「计算手艺」那一半——这恰好是你现在开始学代码的意义所在。
>
> 所以对选校而言，它给你的角度是：更贴合计算设计里偏设计研究 / HCI / 思辨设计的那一端，而不是纯技术 / 参数化那一端（至少在你补齐编程能力之前）。看重研究方法、问题框定、以人为中心 / 交互的项目能让它直接加分；工程味更重的计算设计项目，则会把它当研究能力的佐证，同时期待你在别处拿出实打实的技术作品。
>

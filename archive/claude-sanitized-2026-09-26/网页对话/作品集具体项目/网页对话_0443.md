# 作品集具体项目｜轮回机器项目总结与研究生选校分析

### 用户

> 总结我这个project的工作 以供我拿去做未来研究生选校分析

### 助手

> **项目定位**
> 轮回机器：15–20cm 桌面交互装置，作为一项 HRI 实证研究，探究人对非生命机械物产生拟人化情感依恋的发生条件。研究问题不是"造一个会死的机器人"，而是测量依恋机制本身。
>
> **核心机制（差异化所在）**
> 隐藏变量：用户的交互行为会秘密加速装置的"死亡"，把情感投入与对象损耗对立起来，制造可观测的伦理-情感张力。这是它区别于"机械死亡景观"类作品的根本点——一台被设计来产生可测量数据的实验装置，而非审美表演。选校材料里必须守住这个框架。
>
> **研究方法栈（最强研究信号）**
> 生理信号 EDA / HRV；行为编码 Fischer 框架 + ELAN；量表 IDAQ / IRI / ECR-S / Godspeed。这套组合给作品装上了可投稿的实证骨架，是把"艺术装置"翻译成"研究"的关键资产，也是面对研究型项目时最该前置突出的部分。
>
> **技术与制作能力（工程信号）**
> 全部子系统单人手工完成（SLA/SLS/FDM + 可及 maker 工具，无团队车间）。已展示的能力跨度：多自由度机构设计（肌腱驱动多节手指）、机构自由度分析与约束求解（Hoberman 环 DOF 分析、顶点导轨实现 F=1）、参数化几何 + 物理仿真（Rhino / Grasshopper / Kangaroo2 / rhino3dm）、电机与嵌入式集成（NEMA17 + TMC2209 + 电容触摸 + ESP32）。能同时覆盖概念、机构、电子、代码这四层的人很少，这是面向具身/有形交互方向的稀缺信号。
>
> **当前完成度与短板（诚实评估）**
> 整体约 30–40%。最关键短板是行为引擎架构——它既最欠发展、又对研究价值最核心（决定装置的"行为"如何被人读成生命与意图）。更致命的是：尚无人类被试数据。对研究型申请，被试数据是单一最高杠杆的差异化要素，目前为空。
>
> **对选校的信号映射**
> 强匹配是 MIT Media Lab（Personal Robots / Tangible Media）和 CMU MHCI——它们看重"具身交互 + 实证方法 + 动手制作"的组合，正命中本项目强项。弱匹配是 CMU MSCD 和 ETH/AA 的生成式/空间计算方向，其评价轴（生成系统、空间计算、视觉传达）与本项目"硬件机构 + HRI 实证"的重心错位。做选校分析时别被"计算设计"这个大标签带偏，要逐个看子方向的评价轴是否对齐"机构-实证-制作"这条线。
>
> **申请前的提价杠杆（按优先级）**
> 一、行为引擎：补齐架构，让行为可被解读为有意图，这是概念闭环的前提。
> 二、人类被试数据：哪怕小样本，也能把作品从"装置"升级为"研究"，杠杆最高。
> 三、IRB/伦理审查：时间敏感，趁还有院校归属尽快启动。
> 四、LBW 论文：HRI 或 CHI LBW（4–6页），arXiv 预印本或 in-submission 状态即可显著强化信号。
>

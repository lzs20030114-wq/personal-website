# 作品集具体项目｜宠物空间交互体验

### 用户

> 你觉得和宠物共处的空间交互如何？

### 助手

> 这个候选比它第一眼看上去要强，值得认真过一遍审核标准。
>
> **引擎兼容性：通过，而且方式特别。** 狗公园（或宠物友好的共享空间）有共同在场、彼此感知的身体——只是其中一半身体不是人。关键在于狗在人类互动里扮演的角色：Goffman 的"礼貌性忽视"规范在狗在场时会被合法打破，陌生人可以借狗搭话。这正是 Whyte 说的"三角化"（triangulation）——一个外部刺激物把两个陌生人连起来。街头雕塑和表演者是 Whyte 的例子，狗是日常生活里最强的三角化引擎。而且这有现成的实证文献：Robins、Sanders & Cahill 1991 年就做过狗公园的符号互动论民族志，McNicholas & Collis 做过狗作为社交催化剂的实验。你的实证层书单可以直接续上。
>
> **级联内生性：教科书级别。** 空的狗公园是零价值空间——去那儿的全部意义就是别的狗在。"没有别的狗去所以我不去"是纯粹的网络品逻辑，比很多人类场景还干净。更妙的是里面还藏着一个 Schelling 分选：大狗多了，小狗主人撤离，公园向"大狗场"倾斜，倾斜又加速撤离。一次狗冲突事件可以作为外部点火，之后的退出潮完全通过"谁还在去"的人际传导放大。田野判别问题同样适用：你不带狗去，是因为设施坏了，还是因为没别的狗去？
>
> **双时钟：天然成立，还带循环结构。** 快钟是牵绳距离、狗的游戏聚簇、主人围绕狗形成的交谈三角、冲突事件；慢钟是出勤决策——"六点那批人还去不去"。而且狗公园有很强的时段惯例（晨间群、傍晚群），跟篮球场类似，是慢钟之上再叠一层循环钟。
>
> **归类问题：不要开新方向。** 按你定的路径，它应该先归入现有方向再进场景圈选。它有两个合法归属：**grounds（争夺）**——大狗对小狗、遛狗人对带孩子的家长争夺共享场地；或者 **waiting（陌生人动力学）**——狗作为陌生人接触的触发器。两个都说得通，归哪边取决于你想让哪个机制当主角。这个归类决定应该和悬置的三步审核一起做，不让它插队。
>
> **代价要说清楚。** 第二个物种意味着第二本规则书——狗的行为（游戏鞠躬、追逐信号、冲突升级）需要行为学文献支撑，实证负担接近翻倍。Kuran 的偏好伪装映射不到狗身上，只能映射到主人（"我的狗很友好"的场面话）。北京的合法遛狗空间本身稀缺，田野可达性要核实。
>
> **它独占的东西。** 这是所有候选里唯一一个互动引擎由非人身体驱动的场景，天然接上 more-than-human design 的话语——这对 MIT Media Lab 的口味是加分项。空间智能体的奇幻动词也顺手：狗公园本质上是由围栏定义的空间，一道会迁移、会溶解、会自行分裂成大狗区小狗区再重新合并的围栏，是很干净的"做梦的空间"。
>
> 结论：合法的黑马，级联纯度高于厕所方案，代价是双物种规则书。建议把它挂到 grounds 或 waiting 名下，进入圈选流程一起比。

### 助手

> 这个案例点得很准，但要先说清它给你的是什么：**它不是一个场景，是一个空间动词。**
>
> 猫桌本身的机制是：桌面是给人的光滑工作面，桌体内部是一套只有猫钻得进去的洞穴通道网络——阮昊自己的说法是"把猫的视角带进桌子内部，造出一个人和猫原本不存在的共享空间"。同一块体积，两个物种读出两个完全不同的空间。
>
> **这正好是 Gibson 可供性理论的最纯粹演示。** 可供性从来不是物体的属性，是"物体×身体"的关系：一个 15 厘米的洞对猫是通道，对人什么都不是。你的规则引擎本来就是手写可供性表，现在这张表升级成**按物种索引的双列表**——同一个空间单元，对人类智能体一列规则，对宠物智能体另一列规则。墙对人是墙，对猫是隧道。这在技术上是一个很干净的扩展：两套不同分辨率的网格嵌套耦合，猫在细网格上跑，人在粗网格上跑，NumPy 完全做得动。理论上还能接 von Uexküll 的环世界（Umwelt）——每个物种活在自己的感知世界里，猫桌是把环世界直接盖成了建筑。这是 more-than-human design 话语的正统入口。
>
> **但猫桌的双尺度是死的——设计一次，永远如此。你的空间智能体可以让它活过来，这才是大招：**
>
> 空间在人尺度和宠物尺度之间**动态重新分配体积**。人的互动级联崩塌、身体撤离时，空间不是死掉，而是把腾出来的体积**降尺度**——收缩、折叠成宠物尺度的迷宫层。反过来，宠物层也可以当诱饵：空间故意在人的高度开一个窥视孔，让人看见猫在墙体内部穿行，用三角化把陌生人重新钓回来——这是"catalyst 按分钟行动"的完美具象。
>
> 这里面藏着一个比出勤滞回更狠的滞回：**被降尺度吃掉的体积，回不来了。** 人走了，猫的隧道长进了墙体；等原参数恢复、人想回来时，空间已经物理上属于另一个尺度的身体。滞回从"心理锁死"升级成"空间锁死"——这是能直接画出来的画面，比曲线图强得多。
>
> 它也精确回应了你的合同："真实的人，做梦的空间"。人类层照旧实证——Whyte 的三角化、狗公园民族志都还在；空间层拿到一个现实中不存在的新动词：**rescale / 变尺度**。加进你的动词表，和 merge、migrate、split、dissolve 并列。
>
> 一个提醒：别让这个案例把你往家具设计方向带。猫桌是产品，你的项目是模拟——它的价值是给"宠物方向"补上了此前缺的那个奇幻空间动词，让这个方向从"狗公园级联"升级成"人与宠物之间的体积争夺战"。归类决定不变：它还是挂在 grounds 或 waiting 下面，等三步审核一起走。

### 用户

> 可以，但是这个就需要我们好好研究，我们的立场是什么 我们希望引导什么样子的互动了呗？

### 助手

> 对，这一步躲不掉。而且它其实就是你之前悬置的那件事——"把五种空间欲望形式化成效用函数"——的前置问题：**先定立场，才知道空间的效用函数该奖励什么。**
>
> 先把问题拆干净。这个场景里有四条互动通道：人—人（借宠物三角化）、人—宠（跨尺度接触：窥视孔、共享膜、投喂口）、宠—宠（隧道网络里的相遇）、以及所有身体—空间本身。所谓"立场"，就是空间的效用函数给哪条通道加权。不同的加权，是四个完全不同的项目：
>
> **一、空间当调停者。** 效用 = 摩擦最小化，物种冲突越少分越高。空间做的事：把大狗小狗隔开、把怕猫的人和猫错峰。问题很明显——这是智能家居的优化逻辑，产品思维，正好掉进你老师"发现问题解决问题"的那个坑，批判性归零。而且画面无聊：输出是一条变平的冲突曲线。
>
> **二、空间当竞技场。** 体积零和，两个物种争夺，空间只记分。问题：空间退回了被动容器，空间智能体没戏可演，违反你自己的合同；而且终局大概率是一方锁死另一方——崩塌又变回了终点。
>
> **三、空间当红娘（用宠物钓人）。** 空间的欲望是人类共同在场，宠物层是它的诱饵工具：人撤离时，空间故意让猫在墙体里穿行、开窥视孔制造三角化，把陌生人重新钓回来。戏剧性强，级联修复的画面很好看。但有个伦理暗礁：动物被完全工具化了——在 more-than-human 话语里这是会被评审当场戳穿的姿势，"你说多物种，结果猫是人类社交的基础设施"。
>
> **四、空间当第三方——它自己有欲望，且对尺度不忠。** 空间要的只是被身体使用、被感知、被穿行，它不在乎是谁的身体。人来了它向人尺度舒展；人撤了它不挽留，把腾出的体积降尺度让给猫——不是服务猫，是自保，它需要有人住在它的梦里。这个立场下，前三种立场都降级成它的**行为策略**而不是世界观：当调停能换来更多身体它就调停，当勾引有效它就勾引，当人类不可挽回它就改嫁。滞回的叙事也顺了：不是"空间死了"，是"空间跟别人过了"——你回来时它已经不认识你的尺度了。
>
> 我的判断：四是最强的。理由有三。它是唯一让空间智能体拥有完整人格的立场；它在计算上最干净——效用 = 跨物种加权的身体占用×互动密度，一个函数管所有行为；它在伦理上也站得住——猫不是工具，是另一个客户。而且它把"崩塌是反派"这条原则执行得最彻底：崩塌威胁的不再是空间的生存，而是**你和空间的关系**——这比死亡更疼，也更像你说的"做梦的空间"。
>
> 但这是作者立场问题，必须你自己签字，不能由我定。判别问题只有一个：**当人类不可挽回地撤离时，你希望观众为谁难过——为消失的人，为得到迷宫的猫，还是为那个换了主人的空间？** 你的答案指向哪儿，立场就是哪个。

> 我是在想一些场景，居家空间 宠物公园广场 甚至是更高议题的：人类城市混凝土森林中的动物空间？

### 助手

> 这三个不是三个平行场景，是同一根**尺度阶梯**上的三级——而且每一级在你的审核标准上，强项和死穴完全不同。分开验：
>
> **居家（猫桌尺度）：快钟最强，慢钟死亡。** 人宠身体协商最纯粹，rescale 动词在这儿最漂亮——客厅一寸寸被猫的隧道层蚕食。但级联内生性直接不过关：家里就一两个人一两只猫，没有人群就没有阈值级联，"没人去所以我不去"的传导链根本不存在。Schelling、Granovetter、Kuran 全体失业。它和候诊室一样是纯快钟室内剧，但连候诊室的陌生人流都没有。**抢救版本是猫咖**：半公共的家宅，陌生人因为猫来，人太多猫躲进墙里、体验崩塌、客流撤退——猫的空间选择本身就是被争夺的资源。这才是这一级里引擎兼容的形态。
>
> **宠物公园/广场：引擎最稳，全指标及格。** 上次已经验过：教科书级联、天然双钟加循环钟。田野可达性其实比"狗公园"更好——北京真正的场景不是正规狗公园（稀缺），是**小区广场的傍晚遛狗圈**，每天准时上演，你楼下就有。这是三级里唯一不需要任何抢救的。
>
> **城市混凝土森林：野心最高，引擎最悬。** 死穴在于人和野生动物的关系恰恰是**回避共同在场**——互动靠痕迹、投喂点、偶遇中介，快钟很薄。但它有两个别处没有的东西。一是 Kuran 在这儿映射得最狠：居民公开签联名信反对投喂、深夜偷偷下楼喂猫——偏好伪装的完美田野形态。二是它独占"生态代谢"这个空间欲望，比厕所方案占得更正当。而且奇幻动词在这一级最壮丽：**动物之城就是人类之城的负形**——管道、缝隙、屋顶、废墟组成的第二座城，随人类的撤离与加密而呼吸涨缩。
>
> 这一级有两个能落地的抢救版本，都在你田野半径内。**清华校园流浪猫网络**：投喂点、喂猫群、猫的领地，投喂者社群和投诉者的争夺，全在步行距离内。更狠的是**天坛长耳鸮—拍鸟人系统**：人群因为"有人群说明有鸟"聚集（信息级联，纯 Whyte），人群过密惊飞猫头鹰，鸟走人散，且鸟不再回来——一个有真实记录的、动物在环内的级联加滞回，崩塌完全内生。
>
> 还有一个顺手的对齐：三级刚好各自坐在一种空间欲望上——居家是记忆与依恋，广场是节奏与戏剧，城市是生态代谢。你的欲望框架第一次有了完整的用武之地。
>
> 两个纪律提醒。第一，宠物方向本身还没通过三步审核进前三，这套圈选做得再爽也是预研，不能让它插队。第二，阶梯不必三选一后全扔：**作品集叙事可以展示整根梯子（图版画三级），模拟只做一级**——一张图讲"从猫桌到城市负形"的尺度野心，代码只对准一个引擎最稳的场景。真要我押：模拟押广场级，图版把居家和城市级当首尾书挡；天坛猫头鹰留作黑马，如果你想要一个有真实死亡记录的故事。

> 两条轨道并行：一条决策，一条手艺。决策要快刀，手艺要早动。
>
> **决策轨道（建议两周内关账）**
>
> 1. **一次坐下来走完三步审核，不再拆散。** 复活权：五个已淘汰方向建议维持死亡——最近所有预研（厕所、宠物、尺度阶梯）没有一个替它们翻案。6 进 3：已有投票指向 rooms / grounds / waiting，确认即可，除非你现在想推翻。宠物方向此时正式归档进 grounds 或 waiting，不开第十二类。
> 2. **方向内圈场景。** 每个方向留 2–3 个候选，用五条硬标准统一打分：引擎兼容、级联内生、双钟（或合法替代）、田野可达、欲望匹配。宠物广场在这一步和公共球场同场竞技，宿舍在 rooms 内竞技。产出三个 finalist。
> 3. **三选一，同时立场签字。** finalist 定了就立刻回答那个判别问题（人撤离时你为谁难过），因为立场不定，效用函数就没法写——立场必须在场景定稿之后、动词表实现之前，这是整个顺序里唯一不能颠倒的一环。
> 4. **定稿前的轻田野。** 给每个 finalist 半天实地，就问那一个判别问题："你不来，是因为它坏了，还是因为没人来？"广场遛狗圈就在楼下，成本最低。
>
> **手艺轨道（现在就开始，不等决策）**
>
> Python 零基础起步：第一周 Colab + NumPy 基本功；第二三周在网格上手写 Schelling，再加 Granovetter 阈值。这两个是指法练习，代码注定扔掉——它们不违反你"问题向上"的原则，因为练的不是方向，是肌肉：网格、邻域、迭代、出图。等决策关账，两轨合流，开始写场景专属的双列可供性表、动词表和双钟架构。
>
> **为什么是这个顺序：** 申请季 12 月截止，倒推只剩不到五个月。场景决策不需要五个月，代码学习需要——所以决策必须速决，代码必须今天动。眼下最大的风险不是选错场景，是圈选变成无限游戏：每次预研都在往候选池里加东西（厕所、猫咖、天坛猫头鹰），不关账，池子只会越来越满。
>
> 先不要做的两件事：不要先画图版剪视频（那是有模拟结果之后的事），不要先形式化五个欲望函数（那是立场签字之后的事）。

> 没否，恰好相反——上一轮我押的注就是它（"模拟押广场级"）。可能是"归档进 grounds 或 waiting、不开第十二类"这句读起来像判了降级，所以说清楚我到底裁了什么：
>
> **它通过了所有硬审核。** 引擎兼容（共同在场的身体，还是三级里唯一不需要抢救的）、级联内生（教科书级）、双钟加循环钟、田野可达（楼下）。五个被淘汰的方向死于引擎不兼容，宠物方向不在其中，一票没否过。
>
> **我只否了一件事：它不能当第十二个方向。** 理由是你的十一类是按"人与空间的互动动词"分的，宠物是**参与者，不是动词**。狗广场上演的动词是什么？是争夺（大狗小狗、遛狗人和遛娃家长抢场地）——那就是 grounds；或者是陌生人触发（借狗搭话的三角化）——那就是 waiting。宠物是这两个动词的一种实现方式，不是新动词。类比：宿舍里有猫也不会让宿舍变成新方向，它还是 rooms。再加一层纪律考虑：分类框架是审核开始前关闭的，如果每来一个亮眼候选就开新类，圈选就成了无限游戏——这是我上轮点名的最大风险。
>

> ```python
> import numpy as np
> import matplotlib.pyplot as plt
>
> rng = np.random.default_rng(0)
>
> N = 20            # 场地边长
> n_agents = 5      # 点的数量
> decay = 0.98      # 每拍痕迹衰减
> threshold = 15    # 变色阈值
> steps = 500       # 总拍数
>
> trace = np.zeros((N, N))            # 痕迹场
> blocked = np.zeros((N, N), bool)    # 已变色(不可进入)的格子
> pos = rng.integers(0, N, (n_agents, 2))   # 点的初始位置
>
> snapshots = {}
> moves = np.array([[1,0],[-1,0],[0,1],[0,-1]])
>
> for t in range(steps + 1):
>     if t in (0, steps//2, steps):             # 存三张快照
>         snapshots[t] = trace + blocked * threshold * 1.5
>     for i in range(n_agents):
>         step = moves[rng.integers(4)]
>         new = np.clip(pos[i] + step, 0, N-1)  # 不出界
>         if not blocked[new[0], new[1]]:       # 变色格不可进入
>             pos[i] = new
>         trace[pos[i][0], pos[i][1]] += 1      # 留痕
>     trace *= decay                             # 衰减
>     blocked |= (trace > threshold)             # 超阈值 -> 永久变色
>
> fig, axes = plt.subplots(1, 3, figsize=(12, 4))
> for ax, (t, snap) in zip(axes, snapshots.items()):
>     ax.imshow(snap, cmap='inferno')
>     ax.set_title(f't = {t}')
>     ax.axis('off')
> plt.show()
> ```
>

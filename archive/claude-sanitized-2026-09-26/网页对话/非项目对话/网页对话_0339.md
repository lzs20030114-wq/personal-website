> 浮在 GH 画布上的实时 Rhino 视口窗口——你说的应该是 **Rhino 自带的 "Floating Viewport"** 功能，不是插件。
>
> 操作方法:在 Rhino 里右键点击视口标签(比如 Perspective),选 **"Floating Viewport"**,就会弹出一个独立的浮动视口窗口,可以拖到 Grasshopper 画布上方。这样你调 GH 参数的时候就能实时看到 Rhino 里的几何体变化,不用来回切窗口。
>
> 如果你要的是更集成的方案(比如窗口直接嵌在 GH 画布内、跟着画布缩放那种),那可能是 **Human UI** 或 **Metahopper** 之类的插件,但纯粹"浮动的 Rhino 视口"用 Rhino 原生功能就够了。

> 怎么在rhino里直接下载这个？ 我记得是有这个功能的

### 助手

> 有的,Rhino 里用 **`_PackageManager`** 命令(老版本叫 `_TestPackageManager` 或者 Yak)。
>
> 操作步骤:
>
> 1. 在 Rhino 命令行输入 `PackageManager` 回车
> 2. 弹出的窗口里搜 `TopMostViewport`
> 3. 选中后点 **Install**
> 4. 重启 Rhino
>
> 装完后在命令行输入 `_TopMostViewport` 就能启动浮窗了。
>
> 不过要提醒一下:TopMostViewport 比较老,是给 Rhino 5 做的,不一定在 Package Manager 里能搜到,也不保证在 Rhino 7/8 上稳定运行。如果 Package Manager 里搜不到,就得去 Food4Rhino 官网下 .rhp 文件手动装(Tools → Options → Plug-ins → Install)。

### 助手

> GhCanvasViewport 用法很简单,装完之后:
>
> ## 基本操作
>
> 1. **确认安装成功** — 重启 Rhino 和 Grasshopper,打开 GH 后在组件面板里应该能看到多出来的组件(通常在 Params 或 Display 分类下),或者直接在画布上双击搜 `viewport` / `canvas viewport`
>
> 2. **放到画布上** — 把组件拖到 GH 画布,它会显示成一个矩形区域,里面实时渲染 Rhino 当前视口的画面
>
> 3. **交互** — 鼠标在这个区域里可以旋转/平移/缩放视角,和在 Rhino 视口里操作一样(中键转、Shift+中键平移、滚轮缩放)
>
> 4. **缩放组件大小** — 拖组件边缘可以改变视口窗口的大小
>
> ## 常见问题
>
> - **看不到组件** — 检查 Rhino 的 Tools → Options → Plug-ins 里有没有加载成功,有时候需要手动勾选启用
> - **画面不更新** — 确保 GH 的 preview 是开着的,右键组件看有没有 refresh / enable 选项
> - **性能卡顿** — 这个插件是实验性的(McNeel 官方但非正式产品),复杂模型可能会卡,正常现象
>
> ## 说实话的提醒
>
> GhCanvasViewport 我记得是 **McNeel 的一个 GitHub 实验项目**,不是成熟产品,可能:
> - 没有详细文档
> - 某些 Rhino 版本兼容性差
> - 功能比较简陋(就是个视口镜像,没什么额外设置)
>
> 如果你装完发现组件找不到,或者用起来很别扭,我建议退回到我上条说的方案:**Rhino 原生浮动视口 + PowerToys 置顶**(Win+Ctrl+T),这个组合更稳定、体验更好。
>
> 你装完之后组件能找到吗?双击画布搜 viewport 看看出不出来。

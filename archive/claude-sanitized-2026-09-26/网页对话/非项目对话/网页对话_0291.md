# 非项目对话｜Arduino IDE安装问题

### 用户

> 安装arduino ide装不进来 这是为何

### 助手

> 这个错误是 **"无法写入文件"**，通常是以下几个原因：
>
> **最常见原因：杀毒软件拦截**
>
> Windows Defender 或其他杀毒软件会在安装过程中锁定临时文件，导致写入失败。
>
> 解决方法：暂时关闭实时保护 → 重新安装 → 装完再开启。
>
> **其他可能原因及解决方法：**
>
> 1. **以管理员身份运行安装包** — 右键安装程序 → "以管理员身份运行"
>
> 2. **临时文件夹权限问题** — 按 `Win+R` 输入 `%temp%`，手动清空里面的文件，再重试
>
> 3. **安装包本身损坏** — 重新去 [arduino.cc]([已隐去url]) 下载，建议选 **Windows MSI installer** 版本
>
> 4. **用户名包含中文** — 你的路径里有 `ADMINI~1.DES`，如果完整用户名是中文，临时路径可能解析异常。可以尝试把安装包复制到 `[已隐去windows_path] 根目录再运行
>
> **推荐步骤：**
>
> 先试管理员运行 + 关闭杀毒，大概率能解决。如果还不行，检查一下你的 Windows 用户名是否含中文字符。

### 用户

> msi installer有什么不同？

### 助手

> **MSI vs EXE 安装包的区别：**
>
> MSI 是微软官方的安装格式，由 Windows 系统本身来管理安装过程，权限处理更稳定，出现"无法写入文件"这类问题的概率更低。
>
> EXE 是安装程序自己管理解压和写入过程，需要自己处理临时文件夹，更容易被杀毒软件拦截。
>
> 对你的情况来说，两者装完的 Arduino IDE 功能完全一样，只是安装方式不同。你的报错正好是出在临时文件写入环节，所以换 MSI 版本值得一试。

### 助手

> 两个错误合起来看，问题很清晰：
>
> **核心问题：权限不足**
>
> 错误信息明确说 "Verify that you have access to that directory"，error code 2350 也是 MSI 的权限写入错误。
>
> 路径是 `[已隐去windows_path] Administrator 账户，但安装时没有以管理员权限运行。
>
> **解决步骤：**
>
> 1. 先把之前装了一半的 Arduino 卸载干净（控制面板 → 程序 → 卸载）
> 2. 右键 MSI 安装包 → **以管理员身份运行**
> 3. 如果还报错，安装路径改到 `[已隐去windows_path] 而不是默认的 AppData 路径
>
> 如果以上都不行，还有一个稳妥方案：下载 **ZIP 版本**（arduino.cc 上有提供），直接解压到 `[已隐去windows_path] exe 就能用，完全绕过权限问题。

### 用户

> 怎么迁移安装文件默认盘？

### 助手

> 你是说想把安装路径从 C 盘改到其他盘（比如 D 盘）吗？
>
> 在 MSI 安装过程中直接改就行：
>
> **安装时修改路径：**
> 运行安装包 → 出现安装路径选择界面 → 把 `[已隐去windows_path] 改成 `[已隐去windows_path] → 继续安装
>
> ---
>
> 不过你现在的问题其实不是盘的问题，是**权限问题**。就算装到 D 盘，如果不用管理员身份运行，可能还是会报同样的错。
>
> 建议先**右键管理员身份运行**，路径可以顺手改到 D 盘，两个问题一起解决。

### 用户

> 没有管理员权限选项

### 助手

> 这是 Windows 11 的新版右键菜单，"以管理员身份运行"被收起来了。
>
> 点最底部的 **"显示更多选项"** → 就会出现完整的旧版右键菜单 → 里面有"以管理员身份运行"。

### 助手

> 这个菜单里没有"以管理员身份运行"，是因为你右键的是 **.msi 文件**，MSI 格式默认不显示这个选项。
>
> **解决方法：**
>
> 用命令行强制以管理员权限运行：
>
> 1. 按 `Win+S` 搜索 **cmd**
> 2. 右键 cmd → **以管理员身份运行**
> 3. 输入命令（路径换成你的 MSI 实际位置）：
>
> ```
> msiexec /i [已隐去windows_path]
> ```
>
> 这样就等于用管理员权限启动安装程序了。

### 用户

> 分析一下为什么我一下就损坏

### 助手

> 看你的路径和之前的报错，有几个线索：
>
> **最可能的原因：火绒在拦截**
>
> 右键菜单里看到你装了**火绒安全软件**，火绒会在下载过程中扫描文件，有时会截断或修改安装包导致损坏。下载前可以暂时关掉火绒的实时防护。
>
> **其次：下载来源问题**
>
> 不知道你是从官网直接下的还是第三方渠道，如果是国内镜像站或者其他地方下的，本身就可能不完整。
>
> **验证方法：**
>
> 官网下载页面会提供文件的 SHA256 校验码，下载完可以验证文件是否完整。不过对你来说直接换 ZIP 版本更省事，ZIP 解压完就能看出来文件是否正常。

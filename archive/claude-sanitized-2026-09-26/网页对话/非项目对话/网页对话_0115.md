# 非项目对话｜PDF文件压缩方法

### 用户

> pdf太大了 我想给他弄小点怎么办

### 助手

> 压缩 PDF 有几种方法，取决于你的具体情况：
>
> **最简单的方式：**
>
> 1. **在线工具** — iLovePDF、Smallpdf、Adobe Acrobat Online 都可以免费压缩，直接上传就行
>
> 2. **macOS 预览** — 导出时选择「Quartz 滤镜 → Reduce File Size」
>
> 3. **Adobe Acrobat** — File → Save as Other → Reduced Size PDF
>
> **如果需要更精细控制：**
>
> 你可以把 PDF 传给我，我帮你压缩。压缩效果取决于 PDF 里的内容 - 如果主要是图片，压缩空间比较大；如果是纯文字，本身就很小了。
>
> 你的 PDF 大概多大？里面主要是什么内容？

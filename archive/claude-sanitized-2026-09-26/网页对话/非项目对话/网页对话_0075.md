> **CS61A 是 UC Berkeley（加州大学伯克利分校）的一门具体课程**，全称是 "Structure and Interpretation of Computer Programs"（计算机程序的构造和解释）。
>
> 它是伯克利 CS 专业学生的第一门核心课，在业界名气很大，被认为是最好的 CS 入门课之一。

>
> 伯克利把所有课程资料都免费公开了——视频、讲义、作业、项目全都能在网上找到。所以即使不是伯克利学生，也能完整地学这门课。
>
> 网址是 cs61a.org
>
> **它和普通 Python 教程的区别：**
>
> 普通教程教你"Python 怎么写"，CS61A 教你"程序应该怎么思考"。涉及函数式编程、递归、抽象、数据结构设计这些更底层的概念。
>
> **对你来说：**
>
> 自学 CS61A 能提升能力，但拿不到正式学分。如果你到 San Diego 后想要有成绩单证明，可以考虑在当地社区大学选类似的 CS 入门课，内容相近但能拿官方学分，对申研更有说服力。

### 助手

> `dir()` 是 Python 的一个内置函数，用来**查看一个对象有哪些属性和方法**。
>
> **简单例子：**
>
> ```python
> name = "hello"
> print(dir(name))
> ```
>
> 会输出一长串字符串能用的所有方法，比如 `.upper()`、`.lower()`、`.split()` 等等。
>
> **实际用途：**
>
> 当你不知道某个东西能干嘛时，用 `dir()` 看一眼就知道它有哪些功能可以用。相当于快速查说明书目录。
>
> 你在哪里看到这个的？视频里还是代码里？

### 助手

> 这是 Python 三种常用集合类型的对比总结：
>
> | 类型 | 符号 | 有序 | 可改 | 允许重复 |
> |------|------|------|------|----------|
> | **List** | `[]` | ✓ | ✓ | ✓ |
> | **Set** | `{}` | ✗ | 可增删 | ✗ |
> | **Tuple** | `()` | ✓ | ✗ | ✓ |
>
> **用设计工作打比方：**
>
> - **List（列表）**：像一个可以随时增删改的图层列表，顺序固定，可以有重复图层名
> - **Set（集合）**：像一个去重后的材料清单，不管顺序，自动去掉重复项
> - **Tuple（元组）**：像一个锁定的坐标点 `(x, y, z)`，定了就不能改，读取更快
>
> **实际使用场景：**
>
> ```python
> # List - 最常用，什么都能干
> layers = ["墙体", "门窗", "家具", "墙体"]
>
> # Set - 需要去重时用
> materials = {"木材", "玻璃", "混凝土", "木材"}  # 自动变成3个
>
> # Tuple - 固定不变的数据
> point = (10.5, 20.3, 0)
> ```
>
> 日常写代码 List 用得最多，Set 和 Tuple 特定场景才用。

# 非项目对话｜视频生成中的人物一致性保证

### 用户

> 我正在生成视频 如何保证人物前后一致性

### 助手

> 人物一致性是 AI 视频目前最核心的痛点之一，没有单一按钮能解决，本质上要靠"锚点 + 工作流"来控。你用的是哪个工具会影响具体做法，但通用思路是这样的：
>
> **1. 先做角色资产，不要直接文生视频**
>
> 最有效的方法是先创建一张高质量的参考图或角色设定表（character sheet），设定固定的身份提示词，在各个场景复用相同的视觉描述。实操上通常是：用图像模型（即梦、Midjourney、nano banana / Qwen-Edit 等）先把角色的三视图或多角度设定图做出来，之后所有分镜都从这个资产出发，而不是每次让视频模型凭空生成。
>
> **2. 用"图生视频"而非"文生视频"**
>
> 流程是剧本→分镜→提示词→图像生成→图生视频→剪辑。先用图像模型的角色参考功能生成每个分镜的静态首帧（上传主体物+提示词控制动作道具，人物相似度可达90%以上），再逐镜头图生视频。静态图这一步锁定了长相，视频模型只负责"动起来"，漂移空间小得多。
>
> **3. 用工具自带的角色参考/主体参考功能**
>
> 现在主流工具基本都有这个功能：即梦的"参考角色"、Vidu 的参考生视频、可灵的多主体参考、Sora/S2 的角色固定功能等。S2 更新了固定角色功能，生成视频后能保存角色，下次可以用这个角色形象进行多人创作。如果你走开源 ComfyUI 路线，还有字节的 Phantom 这类专门为单/多主体参考设计的框架，或者给特定角色训 LoRA——一致性上限最高，但门槛也最高。
>
> **4. 控制变量，减少漂移诱因**
>
> 模型每次生成都会重新解读提示词、参考图、机位、风格描述，输入的微小变化会在输出中产生可察觉的变化。所以：身份描述词一字不改地复用；把长剧情拆成短镜头，保持合理的镜头运动（大幅转头、快速运镜最容易崩脸）；光线和风格描述也要统一，同一角色在柔和动漫光和写实电影光下会显得像两个人。
>
> **5. 接受废片率，靠审片和剪辑兜底**
>
> 每推进一个场景前，对照原始角色设定审核，崩了就重roll或者只保留崩之前的片段，剪辑时用转场遮掉不一致的瞬间。
>
> 你现在用的是哪个工具（即梦/可灵/Vidu/Runway/ComfyUI 本地）？做的是写实人物还是动漫角色？这两点定了我可以给你更具体的操作路径——不同工具的角色参考功能用法差别挺大。

### 用户

> 具体 prompt格式

### 助手

> 直接给你可复用的模板。核心原则：**身份描述是一个"锁死不变"的文本块，每条 prompt 都原样粘贴，只改动作/镜头/环境部分。**
>
> ## 第一步：角色设定图（图像模型用）
>
> 生成三视图/设定表的 prompt：
>
> ```
> 角色设定表，三视图（正面、侧面、背面），全身，白色背景，
> [角色身份块]，
> 统一光线，无阴影，角色参考图风格
> ```
>
> 英文版（Midjourney/国外工具通常英文更稳）：
>
> ```
> character design sheet, three views (front, side, back), full body,
> standing pose, plain white background,
> [IDENTITY BLOCK],
> neutral lighting, character reference sheet style --ar 16:9
> ```
>
> ## 第二步：身份块（Identity Block）——这是关键
>
> 写死一段 5–8 个具体特征的描述，之后**一个字都不改**。特征要选"可辨识且稳定"的，不要写模糊形容词：
>
> ```
> 25岁中国女性，圆脸，齐肩黑色直发带碎刘海，左眼角有一颗小痣，
> 细金丝圆框眼镜，穿浅驼色高领毛衣和深棕色灯芯绒外套，
> 银色小圆耳钉，身材偏瘦，165cm
> ```
>
> 要点：
> - ✅ 写具体锚点：发型长度+颜色、脸型、痣/眼镜/耳钉等标志物、服装的**颜色+材质+款式**
> - ❌ 不要写"漂亮""气质好""时尚"这类模型每次理解都不同的词
> - 服装是最容易崩的，颜色和款式必须写死；如果剧情要换装，换装后就是一个新的身份块，同样锁死
>
> ## 第三步：分镜首帧图（图生图 + 角色参考）
>
> 在即梦/nano banana/Qwen-Edit 里上传设定图作为参考，prompt 结构：
>
> ```
> [身份块，原样粘贴]，
> [动作]：坐在咖啡馆窗边，双手捧着白色马克杯，
> [表情]：微笑看向窗外，
> [镜头]：中景，平视角度，
> [环境]：午后咖啡馆，暖色调，窗外虚化街景，自然侧光
> ```
>
> ## 第四步：图生视频
>
> 上传分镜首帧，视频 prompt **不要重复描述外貌**（首帧已经锁定了，重复描述反而给模型漂移的借口），只描述运动：
>
> ```
> 她缓慢转头看向镜头，轻轻放下杯子，微笑。
> 镜头固定，轻微推近。自然光线不变。
> ```
>
> 要点：
> - 动作写 1–2 个就够，一个 5 秒镜头塞太多动作必崩
> - 加"镜头固定/缓慢平移"这类约束，快速运镜和大幅转身最容易崩脸
> - 结尾加"光线不变/风格一致"作保险
>
> ## 反向提示词（支持 negative prompt 的工具）
>
> ```
> 换脸，面部变形，五官不一致，服装变化，多余的人，
> morphing face, inconsistent identity, changing clothes, extra person
> ```
>
> ## 一个完整例子（首帧图）
>
> ```
> 25岁中国女性，圆脸，齐肩黑色直发带碎刘海，左眼角有一颗小痣，细金丝圆框眼镜，穿浅驼色高领毛衣和深棕色灯芯绒外套，银色小圆耳钉。
> 她站在美术馆白色展墙前，侧身看一幅画，双手插在外套口袋里。
> 全景，稍仰视角度，冷白展厅灯光，极简空间。
> ```
>
> 下一个分镜只换第二、三行，第一行永远不动。
>
> 实操建议：把身份块存在备忘录里当"角色档案"，多角色就多个档案。如果你告诉我具体用哪个工具（即梦/可灵/Vidu/Sora），我可以按它的参数语法（比如即梦的参考强度、可灵的多主体标注方式）再细化一版。

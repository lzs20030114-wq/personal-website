# 非项目对话｜寻找免费PDF阅读器

### 用户

> 我adobe账号过期了 现在电脑上没有一个可用的方便的pdf阅读器 你看看我可以去哪搞一个

### 助手

> 其实不用花钱，免费好用的选择很多：
>
> **如果是 Windows：**
> - **SumatraPDF** — 我最推荐的，开源、极轻量（几 MB）、打开速度飞快，纯阅读场景基本无敌。去 sumatrapdfreader.org 下载
> - **PDF-XChange Editor** — 免费版功能就很全，能标注、高亮、填表单，比 Adobe Reader 还流畅
> - **Edge 浏览器** — 系统自带，直接拖 PDF 进去就能看，还能手写标注，应急完全够用
>
> **如果是 Mac：**
> - 系统自带的**预览（Preview）**就很强了，阅读、标注、签名、合并页面都能做，大部分人根本不需要装别的
>
> **如果你需要编辑/OCR 这类重功能：**
> - 福昕（Foxit）免费版，或者 PDF24（网页版工具集，合并拆分压缩转换都免费）
>
> 如果只是日常看文献和作品集 PDF，SumatraPDF（Win）或预览（Mac）就够了，不用装任何臃肿的东西。你是 Windows 还是 Mac？我可以再具体说说。

### 用户

> windows 我还需要一些基础的编辑功能 比如合并拆分 放置签名

### 助手

> Windows + 需要合并拆分和签名的话，我直接推荐一个组合：
>
> **主力装：PDF-XChange Editor（免费版）**
>
> 去 pdf-xchange.com 下载（选 Editor，不是 Viewer），免费版就能覆盖你说的全部需求：
>
> - **阅读** — 流畅度和标注体验都比 Adobe Reader 好
> - **签名** — 支持手绘签名、导入签名图片、放置图章，位置大小随便调
> - **基础编辑** — 高亮、批注、填表单都没问题
>
> 注意一点：免费版里少数高级功能（比如直接改 PDF 正文文字）用了会在页面上加水印，用之前它会弹提示告诉你这是付费功能，看到提示取消就行，不会误伤。你说的合并拆分签名这些都不在水印范围内。
>
> **合并拆分备用：PDF24 Creator**
>
> pdf24.org，德国公司做的，完全免费无水印。既有网页版也有桌面版（桌面版离线处理，作品集这种大文件或者不想上传的文件用它更放心）。合并、拆分、压缩、页面重排、PDF 转图片全都有，界面简单粗暴。
>
> 实际用法上，我建议日常阅读+签名用 PDF-XChange，批量合并拆分压缩扔给 PDF24 桌面版，两个都是绿色免费软件，加起来不到 100MB，基本能 100% 替代你原来 Acrobat 的日常用途。

### 助手

> 选默认的第一个 **64 bit MSI Installer（376.1 MB）** 就行，直接点 DOWNLOAD。
>
> 现在的电脑基本都是 64 位系统，MSI 是标准安装包，装完会正常出现在开始菜单、注册文件关联（以后双击 PDF 直接用它打开）。
>
> 其他几个选项解释一下，方便你判断：
>
> - **Portable Version（便携版）**：解压即用、不用安装，适合放 U 盘或者不想在系统里留痕迹的场景。如果你想要更轻量，选 **Editor Portable Version (x64)** 也完全可以，缺点是不会自动关联 PDF 文件类型
> - **No OCR 版本**：去掉了扫描件文字识别功能所以体积小很多。你以后可能会扫描签字文件或看扫描版文献，建议保留 OCR
> - **32 bit / ARM64**：老电脑或 ARM 芯片的 Windows 笔记本才需要，你大概率用不上
>
> 装的时候注意一步：安装向导里如果出现让你选 **Free Version** 还是试用 Pro 的界面，选 Free Version，别选试用——试用期结束后付费功能会变成加水印的陷阱选项，一开始就用免费模式最干净。

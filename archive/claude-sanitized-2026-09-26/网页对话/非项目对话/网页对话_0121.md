> # List Comprehension 详解
>
> ## 基本概念
>
> List comprehension 是 Python 创建列表的**简洁语法**，把原本需要多行的循环压缩成一行。
>
> ---
>
> ## 基本结构
>
> ```python
> [表达式 for 变量 in 可迭代对象]
> ```
>
> 拆解一下：
> - **表达式**：每次循环要放进列表的东西
> - **变量**：循环中的临时变量
> - **可迭代对象**：要遍历的东西（列表、range、字符串等）
>
> ---
>
> ## 对比理解
>
> ### 传统写法
> ```python
> squares = []
> for x in range(5):
>     squares.append(x ** 2)
> # 结果：[0, 1, 4, 9, 16]
> ```
>
> ### List Comprehension
> ```python
> squares = [x ** 2 for x in range(5)]
> # 结果：[0, 1, 4, 9, 16]
> ```
>
> ---
>
> ## 带条件的 List Comprehension
>
> 可以加 `if` 来过滤：
>
> ```python
> [表达式 for 变量 in 可迭代对象 if 条件]
> ```
>
> ### 例子：只要偶数的平方
> ```python
> # 传统写法
> result = []
> for x in range(10):
>     if x % 2 == 0:
>         result.append(x ** 2)
> # 结果：[0, 4, 16, 36, 64]
>
> # List Comprehension
> result = [x ** 2 for x in range(10) if x % 2 == 0]
> # 结果：[0, 4, 16, 36, 64]
> ```
>
> ---
>
> ## 你那个老虎机的例子
>
> ```python
> [random.choice(symbols) for _ in range(3)]
> ```
>
> 阅读顺序：
> 1. `for _ in range(3)` → 循环3次
> 2. `random.choice(symbols)` → 每次随机选一个符号
> 3. `[...]` → 把结果收集成列表
>
> `_` 是 Python 的惯例，表示"这个变量我用不到，只是需要循环3次而已"。
>
> ---
>
> ## 更多例子
>
> ```python
> # 把字符串每个字母变大写
> letters = [char.upper() for char in "hello"]
> # 结果：['H', 'E', 'L', 'L', 'O']
>
> # 从列表中筛选大于5的数
> nums = [1, 8, 3, 9, 2, 7]
> big = [n for n in nums if n > 5]
> # 结果：[8, 9, 7]
>
> # 处理嵌套：二维坐标
> coords = [(x, y) for x in range(3) for y in range(3)]
> # 结果：[(0,0), (0,1), (0,2), (1,0), (1,1), (1,2), (2,0), (2,1), (2,2)]
> ```
>
> ---
>
> ## 什么时候用？
>
> | 情况 | 建议 |
> |------|------|
> | 简单转换/筛选 | ✅ 用 list comprehension |
> | 逻辑复杂、多步操作 | ❌ 用传统循环，更清晰 |
> | 需要 break/continue | ❌ 只能用传统循环 |
>

>

>

>
> 就像建筑图纸：
>
> - **形参（parameter）** = 图纸上写的"门宽 = X"
> - **实参（argument）** = 实际施工时说"X = 900mm"
>
> 函数定义时不知道具体值是多少，调用时才确定。
>
> ---
>
> ## 名字可以不同
>
> ```python
> def input_bet(b):          # 叫 b 也行
>     if bet > b:
>         print("不够")
>
> def main():
>     balance = 100
>     input_bet(balance)     # 把 balance 的值传给 b
> ```
>
> 传的是**值**，不是变量名本身。

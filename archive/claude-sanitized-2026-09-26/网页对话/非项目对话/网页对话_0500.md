# 非项目对话｜Kimi K3开源模型接入指南

### 用户

> kimi k3最近发布 能力很强还是开源模型 我可以不可以学习一下如何使用这个开源模型作为我们treepractice网站背后的模型？

### 助手

> 可以，接入本身对你的技术栈来说不难，但先把一个关键点说清楚：K3 参数规模 2.8 万亿，是目前全球参数最大的开源模型——这个体量意味着你不可能自己部署它，"开源权重"对个人开发者基本没有实际意义。所以实践中"用 K3"就是调月之暗面的官方 API，模型名 kimi-k3，和调用任何闭源模型的方式完全一样。
>
> 成本要先算：每百万 token 输出 100 元、未命中输入 20 元、缓存命中输入 2 元。输出价不算便宜，而且官方自己也说整体表现仍落后于最强的闭源模型。所以要不要上旗舰，取决于 treepractice 里模型具体做什么——简单任务用更小的模型性价比高得多。
>
> 接入路径（Next.js + Vercel 很顺）：
> 1. 在 platform.kimi.com 注册充值、拿 API key
> 2. Key 放 Vercel 环境变量，只在 server route / server action 里调用，绝不能出现在前端代码里
> 3. Moonshot API 兼容 OpenAI 接口格式，用 Vercel AI SDK 配个自定义 baseURL 就能接上，顺手把流式输出做了，避免 serverless 函数超时
>
> 这一套（API 封装、密钥管理、streaming）本身就是很好的全栈练手内容。你打算让模型在网站里具体干什么？这决定该选 K3 还是更便宜的小模型。

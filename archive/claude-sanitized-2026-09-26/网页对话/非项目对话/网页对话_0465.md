# 非项目对话｜Git中PR的含义

### 用户

> pr是什么意思 在git语境下 简短的解释

### 助手

> PR = Pull Request（拉取请求）。
>
> 它是你在 GitHub 等平台上向某个仓库提交代码改动的请求。流程大致是：你把改好的代码推到自己的分支，然后发起一个 PR，请求把你的改动合并（merge）到目标分支（比如 main）。仓库维护者可以在 PR 里查看你的代码、评论、要求修改，确认没问题后点击合并。
>
> 简单说就是：**"我改好了一些东西，请你审核一下要不要合进去。"**
>
> 它的作用一是代码审查（别人帮你把关），二是讨论记录（改动的来龙去脉都留在 PR 里）。你做 treepractice.com 或者以后参与开源项目时会经常用到。

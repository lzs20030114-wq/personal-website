# 非项目对话｜为什么没有lower函数

### 用户

> 为啥没有lower

### 助手

> 问题在第65行：`input()` 的返回值没有赋给 `food`。
>
> ```python
> food = 0
> while True:
>     input("Enter a food to buy(or 'q' to quit)")  # ← 这里！返回值丢失了
>     if food.lower() == "q":
>         break
> ```
>
> 此时 `food` 始终是整数 `0`，而整数没有 `.lower()` 方法，所以会报错类似：
> > `AttributeError: 'int' object has no attribute 'lower'`
>
> **修正：**
> ```python
> while True:
>     food = input("Enter a food to buy(or 'q' to quit)")  # 把输入赋给 food
>     if food.lower() == "q":
>         break
> ```
>
> 另外 `food = 0` 这行初始化其实也没必要了，因为循环一开始就会给 `food` 赋值。

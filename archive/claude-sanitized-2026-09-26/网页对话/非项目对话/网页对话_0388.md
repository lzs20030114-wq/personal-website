# 非项目对话｜Installing and using cnki-skills

### 用户

> [已隐去url] 我想要安装这个skills并使用

### 助手

> 我先看看这个仓库的内容，了解它是什么以及怎么安装。
>
> 看明白了。先说一个关键的事情，免得你装完发现不对：
>
> **这个 skills 是给 旧代码助手（命令行工具）用的，不是给你现在正在用的网页版 / 桌面版 旧助手 用的。** 两者完全是两个东西：
>
> - 你现在和我对话的这个界面：旧助手 网页/桌面 App，没办法装这种本地 skills
> - 旧代码助手：服务提供方 出的命令行编程工具，跑在你电脑的终端里，可以装第三方 skills 和 MCP server
>
> 所以要用这套 cnki-skills，得先装 旧代码助手。你之前应该在 Windows 上配过 旧代码助手（PowerShell + V2RayN 那次），如果还在的话就能直接接着用。
>
> ---
>
> ## 安装步骤（确认你有 旧代码助手 后）
>
> ### 1. 装 Chrome DevTools MCP（让 旧代码助手 能控制你的 Chrome）
>
> 打开终端（Windows 用 PowerShell，Mac 用 Terminal），跑：
>
> ```bash
> 旧助手 mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest
> ```
>
> ### 2. 把 skills 装到你的项目里
>
> 先想好你想在哪个文件夹里用这些 skills。比如你专门建一个 `cnki-research` 文件夹来做论文研究：
>
> ```bash
> # 进到你想用的文件夹，比如
> cd ~/Documents/cnki-research   # Mac
> # 或 cd [已隐去windows_path]   # Windows
>
> # 把 repo 克隆到临时位置
> git clone [已隐去url] /tmp/cnki-skills
>
> # 复制 skills 和 agent 到当前项目的 .旧助手 文件夹
> mkdir -p .旧助手
> cp -r /tmp/cnki-skills/skills/ .[已隐去service_branch]
> cp -r /tmp/cnki-skills/agents/ .[已隐去service_branch]
> ```
>
> Windows 上 `/tmp/` 不存在，改成临时目录就行：
>
> ```powershell
> git clone [已隐去url] $env:TEMP\cnki-skills
> mkdir .旧助手 -Force
> Copy-Item -Recurse $env:TEMP\cnki-skills\skills .旧助手\skills
> Copy-Item -Recurse $env:TEMP\cnki-skills\agents .旧助手\agents
> ```
>
> ### 3. 用远程调试模式启动 Chrome
>
> 这一步很容易踩坑：**必须先把原来开着的 Chrome 全部关掉**，再用下面的命令重新开。不然新开的 Chrome 不会进调试模式。
>
> **Mac：**
> ```bash
> /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
> ```
>
> **Windows（PowerShell）：**
> ```powershell
> & "[已隐去windows_path] Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
> ```
>
> 开完以后在新打开的 Chrome 里手动登录知网（必须登录才能下载 PDF）。
>
> ### 4. 启动 旧代码助手
>
> 回到你刚才放 `.旧助手` 文件夹的那个目录，跑：
>
> ```bash
> 旧助手
> ```
>
> 然后试一下：
>
> ```
> /cnki-search 参数化建筑设计
> ```
>
> 如果出结果就装好了。
>

>
> ## 几个提醒
>
> 1. **知网账号**：你得有清华的知网访问权限。你现在人在美国，清华账号的校外访问可能要走清华的 VPN（webvpn.tsinghua.edu.cn）才能下 PDF，光登录不够。
> 2. **验证码**：知网经常弹腾讯滑块验证码，这个 skill 检测到会停下来让你手动滑，不会自动绕过。
> 3. **Zotero 推送**：可选功能，要你电脑上装着 Zotero 桌面端开着才能用。
>

>
> 要不要先确认一下：你电脑上 旧代码助手 还在不在？以及你现在主要在 Mac 还是 Windows 上操作？我可以根据你的情况把命令写得更具体一点。

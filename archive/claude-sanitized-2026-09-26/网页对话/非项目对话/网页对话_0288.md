# 非项目对话｜v2rayn的终端代理命令在哪

### 用户

> v2rayn的终端代理命令在哪

### 助手

> V2RayN 的终端代理命令可以在软件界面里找到：
>
> 打开 V2RayN → 底部状态栏或设置里会显示本地监听端口（默认一般是 **10808** for SOCKS5，**10809** for HTTP），然后在终端里手动设置：
>
> **Windows CMD：**
> ```
> set http_proxy=[已隐去url]
> set https_proxy=[已隐去url]
> ```
>
> **PowerShell：**
> ```
> $env:http_proxy="[已隐去url]
> $env:https_proxy="[已隐去url]
> ```
>
> **Git Bash / WSL：**
> ```
> export http_proxy=[已隐去url]
> export https_proxy=[已隐去url]
> ```
>
> 具体端口号以你 V2RayN 里实际设置为准，可以在 **设置 → 参数设置 → Core基础设置** 里查看本地监听端口。也可以直接复制——V2RayN 新版本在主界面底部状态栏右键有"复制环境变量"的选项，直接粘贴到终端就行。

# 非项目对话｜V2rayN终端代理命令位置

### 用户

> 我现在需要在v2rayn里找到终端代理命令复制 在哪找?

### 助手

> 在 v2rayN 里找终端代理命令：
>
> 1. 打开 v2rayN 主界面
> 2. 点击左下角 **参数设置**（或菜单栏 → 设置）
> 3. 找到 **Core:系统代理** 或直接看主界面底部状态栏
>
> **更直接的方法：**
>
> 主界面底部有一行小字显示当前监听端口，比如：
> - HTTP 代理端口：`10809`
> - Socks 端口：`10808`
>
> 然后在终端手动输入：
> ```bash
> set http_proxy=[已隐去url]
> set https_proxy=[已隐去url]
> ```
> （Windows CMD）或：
> ```powershell
> $env:http_proxy="[已隐去url]
> $env:https_proxy="[已隐去url]
> ```
> （PowerShell）
>
> **最快的方式：** 直接看 v2rayN 主界面底部状态栏，端口号就在那，默认基本都是 `10809`。

### 用户

> 代理tun模式是干啥用的

### 助手

> 代理的 **TUN 模式**是一种让代理流量接管**系统全局网络**的工作方式。
>
> 普通代理（HTTP/SOCKS）只能代理那些**主动支持代理设置的应用**，比如浏览器。但很多程序——比如命令行工具、游戏客户端、某些 app——根本不走系统代理，直接用自己的网络栈发包，就绕过了代理。
>
> TUN 模式的原理是在系统里创建一个**虚拟网卡（TUN 网卡）**，然后把系统所有的网络流量都路由到这张虚拟网卡上，再由代理软件统一处理。对操作系统来说，所有流量都走这张卡，没有应用能绕过去。
>
> **简单比喻：**
> - 普通模式 = 在门口设个检查站，但有人走后门
> - TUN 模式 = 把整栋楼的出口都封了，所有人必须走同一个门
>
> **实际用处：**
> - 让终端里的 `pip`、`npm`、`git` 等命令也走代理（对你学编程很实用）
> - 让不支持代理的游戏/应用也能走代理
> - 实现真正的全局流量分流控制
>
> 开 TUN 模式一般需要管理员/root 权限，因为要操作系统网络接口。Clash、Surge、sing-box 这类工具都支持这个模式。

# 非项目对话｜GitHub branch概念解释

### 用户

> github里的branch是什么意思

### 助手

> Branch（分支）是 Git 版本控制中的一个核心概念，可以这样理解：
>
> **基本概念**
> Branch 就像是你项目的一条"平行时间线"。你可以在这条分支上做各种修改、实验，而不会影响主项目。
>
> **为什么需要 branch？**
>
> 1. **安全实验** - 假设你想给建筑设计软件添加一个新功能，但不确定效果。你可以创建一个新分支来测试，如果不好就直接删掉这个分支，主项目完全不受影响。
>
> 2. **并行工作** - 多人协作时，每个人可以在自己的分支上工作，互不干扰。比如你在 "feature-floor-plan" 分支上开发平面图功能，同事在 "feature-3d-render" 分支上做三维渲染。
>
> 3. **版本管理** - 可以同时维护多个版本。比如：
>    - `main` 分支：稳定的主版本
>    - `develop` 分支：正在开发的新功能
>    - `hotfix` 分支：紧急修复bug
>
> **实际应用场景（建筑设计相关）**
>
> ```
> main (主分支 - 稳定版本)
>   ├── feature-parametric-design (参数化设计功能)
>   ├── experiment-new-algorithm (测试新算法)
>   └── fix-cad-export-bug (修复CAD导出问题)
> ```
>
> **基本操作**
> - 创建新分支：`git branch new-feature`
> - 切换分支：`git checkout new-feature`
> - 合并分支：完成开发后，可以把分支的改动合并回主分支
>
> 把 branch 想象成你做建筑设计时的"草稿本" - 你可以在草稿本上随意尝试不同方案，满意了再把方案整合到正式图纸中。不满意的草稿可以直接扔掉，不会影响你的正式作品。

### 助手

> **VS Code 默认创建的是未命名文件，需要你手动保存时指定文件类型**
>
> **解决方法（两种）：**
>
> **方法1：保存时指定文件名**
> 1. 新建文件后（Ctrl+N 或 Cmd+N）
> 2. 按 Ctrl+S（或 Cmd+S）保存
> 3. 在保存对话框里，文件名输入：`test.py`（一定要加 `.py` 后缀）
> 4. VS Code 会自动识别这是 Python 文件，显示代码高亮
>
> **方法2：先设置语言模式**
> 1. 新建文件后
> 2. 点击右下角的 "Plain Text"（纯文本）
> 3. 在弹出的语言列表里选择 "Python"
> 4. 然后再保存时加 `.py` 后缀
>
> **更方便的做法：**
> 直接在你的项目文件夹里：
> 1. 右键 → 新建文件
> 2. 直接命名为 `xxx.py`
> 3. VS Code 会自动识别
>
> **检查是否成功：**
> 如果文件是 `.py` 格式，你会看到：
> - 右下角显示 "Python" 而不是 "Plain Text"
> - 代码有颜色高亮（比如 `print` 显示为紫色或其他颜色）
> - 左侧文件图标是 Python 标志
>
> 建议你现在试一下：创建一个名为 `hello.py` 的文件，写上 `print("Hello")` 看看是否有颜色高亮。

### 用户

> 为啥vscode里光标会变成小方块 功能会变得不一样啊

### 助手

> **你不小心按到了 Insert 键（或 Ins 键），进入了"覆盖模式"**
>
> **两种编辑模式：**
>
> 1. **插入模式（正常）**
>    - 光标是一条竖线 `|`
>    - 打字时，新字符插入到光标位置
>    - 原有文字向后移动
>
> 2. **覆盖模式（你现在的状态）**
>    - 光标是一个方块 `█`
>    - 打字时，新字符会**替换掉**光标位置的字符
>    - 原有文字被覆盖删除
>
> **解决方法：**
> 再按一次 **Insert 键**（通常在键盘右上区域，Delete 键附近）就能切换回正常模式。
>
> **如果找不到 Insert 键：**
> - 笔记本电脑可能需要按 `Fn + Insert` 或 `Fn + Ins`
> - Mac 键盘可能是 `Fn + Enter`
> - 有些笔记本上 Insert 和其他键共用，标注可能很小
>
> **检查是否恢复正常：**
> 光标变回竖线 `|` 就对了。
>
> 这是个很容易误触的功能，很多人写代码时都遇到过。记住按 Insert 键切换就行，以后再碰到就知道怎么办了。

### 助手

> **两种方法：**
>
> **方法1：用注释符号 `#`（最常用）**
>
> 在代码行前面加 `#`，这行就变成注释，不会运行：
>
> ```python
> username = input("Your username is:")
>
> # if len(username) > 12:
> #     print("Your username should be no more 12 characters")
> elif " " in username:
>     print("Your username must not contain spaces")
> ```
>
> **快捷键（超方便）：**
> - 选中要注释的多行代码
> - 按 `Ctrl + /`（Mac 是 `Cmd + /`）
> - 所有选中的行会自动加上 `#`
> - 再按一次就取消注释
>
> **方法2：用三引号（注释大段代码）**
>
> ```python
> username = input("Your username is:")
>
> """
> if len(username) > 12:
>     print("Your username should be no more 12 characters")
> elif " " in username:
>     print("Your username must not contain spaces")
> """
>
> print("Welcome")
> ```
>
> **区别：**
> - `#` 适合注释单行或几行
> - `"""..."""` 适合注释一大段代码块
>
> **实际演示：**
> ```python
> username = input("Your username is:")
>
> if len(username) > 12:
>     print("Your username should be no more 12 characters")
> # elif " " in username:  ← 这行被注释了，不会检查空格
> #     print("Your username must not contain spaces")
> elif not username.isalpha():
>     print("Your username must not contain numbers")
> else:
>     print(f"Welcome {username}")
> ```
>
> 建议你试试用 `Ctrl + /` 快捷键，选中几行代码按一下，超快！

### 助手

> **因为 Python 把 `0214` 识别成了八进制数（octal number）**
>
> **什么是八进制？**
> - 我们平时用的是十进制（0-9）
> - 八进制只用 0-7 这八个数字
> - 在 Python 中，数字以 `0` 开头会被认为是八进制
>
> **你的代码：**
> ```python
> credit_number = 1234-4312-0214-1251
> ```
>
> Python 看到 `0214`，认为这是八进制数，但 `8` 和 `9` 不能出现在八进制里，所以...等等，`0214` 里没有 8 或 9 啊？
>
> **VS Code 标红的真正原因：**
> 其实是在提醒你：`0` 开头的数字会被当成八进制，这可能不是你想要的。
>
> **更大的问题：你这个代码本身就是错的！**
>
> ```python
> credit_number = 1234-4312-0214-1251
> ```
>
> Python 会把这个理解成**数学减法**：
> - 1234 减 4312 减 214 减 1251 = -4543
>
> **正确的写法（信用卡号应该是字符串）：**
>
> ```python
> credit_number = "1234-4312-0214-1251"
> ```
>
> 加上引号 `" "`，这样就是一个完整的字符串，不会做减法运算。
>
> **试试看：**
> ```python
> # 错误写法
> credit_number = 1234-4312-0214-1251
> print(credit_number)  # 输出：-4543
>
> # 正确写法
> credit_number = "1234-4312-0214-1251"
> print(credit_number)  # 输出：1234-4312-0214-1251
> ```
>
> 信用卡号、电话号码这类数字，虽然是数字，但不用来计算，所以要用字符串存储！

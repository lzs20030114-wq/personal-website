> ## 问题一：如何用AI生成不同语言的反馈
>
> 这个实现非常简单，核心就是 **Prompt里加一个语言指令**。
>
> 你现在给AI的Prompt大概是这样：
>
> ```
> 你是TOEFL写作评分专家，请评估以下Academic Discussion回答...
> [学生的回答]
> 请从任务完成度、语言多样性、连贯性三个维度给出反馈。
> ```
>
> 改成多语言版只需要在Prompt里加一行：
>
> ```
> 请用[TARGET_LANGUAGE]语言给出所有反馈内容。
> 评分标准和分析框架保持不变，但你的所有输出必须用[TARGET_LANGUAGE]写作。
> ```
>
> 其中 `TARGET_LANGUAGE` 根据用户选择的界面语言动态注入，比如：
>
> ```javascript
> const languageMap = {
>   'zh-CN': '简体中文',
>   'zh-TW': '繁體中文',
>   'ja': '日本語',
>   'es': 'español',
>   'en': 'English'
> }
>
> const targetLanguage = languageMap[user.locale] || 'English'
> ```
>
> 旧助手和GPT-4在这五种语言上的反馈质量都很高，日语和西班牙语完全能达到母语级别的解释表达。**不需要额外训练模型，不需要翻译API，改5行代码就能实现。**
>
> 唯一需要注意的细节是：你的系统Prompt本身（评分维度名称、示例短语）也要翻译成对应语言，否则AI可能会混用语言。最简单的做法是维护一份多语言系统Prompt模板文件。

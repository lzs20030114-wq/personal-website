# 非项目对话｜Package location sentence correction

### 用户

> 第 10 题：Your roommate was searching for a recent delivery.
> 答错
> 你的答案：I kept the package where that arrived yesterday is found out.
> 正确答案：I found out where the package that arrived yesterday is kept.

### 助手

> 这道题考的是嵌套定语从句的语序，我们来拆解一下。
>
> 正确答案是 **I found out where the package that arrived yesterday is kept.**
>
> 这句话的结构是这样的：主句是 "I found out"，后面跟一个 where 引导的宾语从句 "where the package is kept"，而 "that arrived yesterday" 是插在中间修饰 package 的定语从句。
>
> 你的版本 "I kept the package where that arrived yesterday is found out" 有几个问题：把 kept 放成了主句动词，意思变成了"我保管了包裹"；found out 被挪到了句尾，语法上断裂了；where 和 that 的从句关系也乱了。
>
> 记住这个嵌套模式：**主语 + found out + where + 名词 + (that + 定语从句) + is kept**。核心是先说"我搞清楚了"，再说"包裹被放在哪里"，定语从句 "that arrived yesterday" 只是补充说明是哪个包裹。

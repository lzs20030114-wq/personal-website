# 非项目对话｜初中题库API接口源搜索

### 用户

> 初中生题库源搜索一下 你帮我找找 最好是那种可以api调用的

### 助手

> 找到了三家能真正走 API 的，外加一家待核实。先说结论：**你们这条"拍错题 → 认知识点 → 推相似题"链路，学科网最对口；想今天就跑通 demo，用有道。** 风险在前面：学科网和菁优都不是自助开通，要走商务谈判，价格不公开，对两个人起步的小项目可能有年费门槛，这点要打电话直接问。
>
> **1. 学科网开放平台（open.xkw.com）— 首选**
> 接口文档是公开的（apifox 上能看），题库 API 里正好有你们需要的四个：章节-知识点推题、举一反三推题、搜题(精品版)、关键词搜题，其中举一反三是 /xopqbm/questions/similar-recommend，传课程 ID 和题目文本就返回相似题。它已经在给小天才学习机提供试题和试卷资源，也通过搜题类 API 为智谱 AI 答疑智能体提供内容，说明对外供给是成熟业务。商业合作电话 010-57402157，客服 400-900-2556。
>
> **2. 菁优网开放平台（jyeoo.com/open）— 备选，可并行谈**
> 3000 多万道 K12 全学科题目，题库每日更新，除题库 API 还有单独的 OCR 试题搜索。每道题包含考点、专题、分析、解答、点评，知识点标签对做错题本很有用。流程是申请合作 → 平台审核 → 洽谈合作 → 接口开发，联系人在页面底部（吴老师，[已隐去phone]）。同样无公开报价。
>
> **3. 有道智云 精品题库 — 最快验证用**
> 唯一能自助注册、按量付费的：平台给每个账户送 50 元体验金，OCR 识别图片里的文字和公式后，在覆盖小初高全科 6000 万题的题库里搜索，返回最匹配的题目和答案，单题搜对率 73% 以上。两个限制：目前只支持单道题搜索，以及它本质是"搜题"而不是"按知识点推题"——能告诉你这道题是什么、考什么，但相似题推荐要靠它顺带返回的相近题，不如学科网那个接口直接。
>
> **4. 全品题库 API** — 知乎上有他们自己的推广帖，说有百万级中小学试题、每日更新的 API，但我没找到公开文档，需要你自己核实。
>
> 开源数据集（HuggingFace 上那些数学题集）我也查了，基本是给大模型训练用的，没有教材版本和知识点标签，商用授权也不清楚，不适合你们。
>
> 打电话给学科网/菁优时建议先问三件事：起步最低年费或最低采购量；初中数学是否覆盖你们当地用的教材版本；题目能否存到自己库里并展示给家长学生端（数据授权范围）。第三条最容易踩坑。

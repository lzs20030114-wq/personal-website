> ## 嵌套类的核心概念
>
> **嵌套类就像建筑图纸中的"内部构件详图"**
>
> 想象一下：
> - `Company` = 一栋建筑的总图纸
> - `Employee` = 这栋建筑专属的门窗详图
>
> 门窗详图只对这栋建筑有意义，不需要单独存在于项目文件夹的根目录——它被"嵌套"在总图纸里。
>
> ## 为什么要这样做？
>
> ```
> class ArchitecturalProject:
>     class Room:  # Room 只在这个项目语境下有意义
>         def __init__(self, name, area):
>             self.name = name
>             self.area = area
> ```
>
> 三个好处：
> 1. **逻辑分组** — Employee 和 Company 紧密相关，放在一起更清晰
> 2. **封装私有细节** — 外部代码不需要知道 Employee 的存在
> 3. **避免命名冲突** — 不同 Company 可以有不同定义的 Employee
>
> ## 代码执行流程
>
> ```python
> company2.add_employee("Sheldon", "Manager")
> ```
>
> 这行代码发生了什么：
> 1. 调用 `add_employee` 方法
> 2. 方法内部用 `self.Employee(name, position)` 创建嵌套类的实例
> 3. 把新员工添加到 `self.employees` 列表
>

> ## "外界不知道"是什么意思？
>
> 不是说**完全无法访问**，而是说**不会意外撞见**。
>
> 对比一下：
>
> ### 普通写法（不嵌套）
>
> ```python
> class Company:
>     pass
>
> class Employee:  # 独立存在于全局
>     pass
> ```
>
> 这时候任何代码都能直接看到 `Employee`：
> ```python
> emp = Employee("Bob", "Cook")  # 直接用
> ```
>
> ### 嵌套写法
>
> ```python
> class Company:
>     class Employee:  # 藏在 Company 里面
>         pass
> ```
>
> 外部代码要访问必须**明确指定路径**：
> ```python
> emp = Employee("Bob", "Cook")           # ❌ 报错，找不到
> emp = Company.Employee("Bob", "Cook")   # ✓ 必须通过 Company
> ```
>
> ## 建筑类比
>
> 想象两种情况：
>
> 1. **不嵌套** = 门窗详图单独放在项目根目录，任何人翻文件夹都能看到
> 2. **嵌套** = 门窗详图夹在某栋楼的总图纸里，只有打开那栋楼的图纸才会看到
>
> "外界不知道"的意思是：**不会在全局命名空间里占位置，不会造成命名污染**。
>
> 这样你可以有：
> ```python
> class Company:
>     class Employee: ...
>
> class School:
>     class Employee: ...  # 不冲突！各自独立
> ```
>

> ## Static Method（静态方法）
>
> ### 核心区别
>
> | | Instance Method | Static Method |
> |---|---|---|
> | **属于** | 对象（实例） | 类本身 |
> | **需要 self** | ✓ 是 | ✗ 不需要 |
> | **能访问对象数据** | ✓ 能 | ✗ 不能 |
> | **调用方式** | `对象.方法()` | `类名.方法()` |
>
> ### 代码解读
>
> ```python
> class Employee:
>     
>     # 实例方法 — 需要 self，操作具体某个员工的数据
>     def get_info(self):
>         return f"{self.name} = {self.position}"
>     
>     # 静态方法 — 不需要 self，只是个工具函数
>     @staticmethod
>     def is_valid_position(position):
>         valid_positions = ["Manager", "Cashier", "Cook", "Janitor"]
>         return position in valid_positions
> ```
>
> ### 调用区别
>
> ```python
> # 静态方法 — 直接用类名调用，不需要创建对象
> Employee.is_valid_position("Rocket Scientist")  # → False
>
> # 实例方法 — 必须先创建对象
> emp = Employee("Bob", "Cook")
> emp.get_info()  # → "Bob = Cook"
> ```
>
> ### 建筑类比
>
> - **实例方法** = 测量某个具体房间的面积（必须指定是哪个房间）
> - **静态方法** = 查建筑规范表（不需要任何具体房间，只是查规则）
>
> `is_valid_position()` 就是个"查表"工具，和任何具体员工无关，所以用 `@staticmethod`。

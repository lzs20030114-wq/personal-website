空间怎么变是我写的规则。人和猫去不去，仍由各自的行为定，只能测出来。

共处于同一空间的不同物种在运动维度、身体尺度与距离阈值上存在系统性差异。既有设计实践通常以功能分区消解这类差异，使各物种的活动范围互不重叠；这一策略回避了物种间相遇，也使空间形态与行为差异脱钩。本项目提出并检验一个相反的假设：若空间构件能够读取共处各方的行为差异并据此重构自身形态，则行为差异可以从设计中待消解的约束转化为形态生成的条件。项目以多智能体仿真为方法，将候选场景归纳为三类人—动物关系，先做其中一类：猫咖里的住户猫与陌生访客。行为规则分两档，有实证出处的阈值直接取用，没有出处的阈值标为演示值。空间响应由天花悬挂的收缩张紧单元阵列承担。

## 研究背景与问题

跨物种共处的室内设计存在一个默认解法：垂直分层。人的家具占据下部空间，猫的攀爬构件贴墙上行，两个物种各自持有一段互不重叠的高度区间。猫咖也是这样，客流一高，猫就上层架（Hirsch 等，2025）。该策略在工程上成立，但其代价是取消了物种间的身体相遇，分层设计使共处退化为并置。

本项目的研究问题是：空间能否不作为行为的容器，而作为行为的响应方参与共处？具体而言，若构成空间的单元能够感知共处各方留下的行为信息并主动改变形态，物种间的行为差异是否能够持续地被转译为空间形态的变化。

## 设计立场

本项目对跨物种空间的界定不采用尺度竞争框架（即"何种身体优先占有体积"），而采用体积再分配框架：空间体积应依据各方的自由行为重新分配，设计目标是空间形态的改造，而非物种间支配关系的裁定。

项目的起点是让空间不承担仲裁功能。单元不判断体积的应然归属，只读取各类身体留下的行为痕迹，停留热区、高频路径、回避区域，再把体积向痕迹所指认的形态转移。这一机制在计算上对应共识主动性（stigmergy）：个体不经直接协商，通过遗留在环境中的信息实现间接协调。其建成环境中的既有对应物是欲望路径（desire path）：铺装最终追认使用者踩踏出的捷径。

第一版平面仿真就是按这个起点做的，单元跟着痕迹落，人走到哪儿哪儿就动。拿它和钉死不动的层架、空房间对照，三十二个种子跑下来，人停在猫身边的次数反而是三档里最少的，10.2 次，固定层架 12.8，空房间 12.6。原因在追认本身。只追认痕迹的空间只会在身体已经在的地方加厚，它追认得出使用，追认不出相遇。 [→ 日志 2026-10-07](/archive#log-2026-10-07-3)

于是空间被给了一个方向。在人猫这一类里它要促成相遇，在人狗那一类里它要分出人与人、狗与狗各自的一片，在人与野生动物那一类里它要动态分隔。方向由人定，空间拿到的只是方向，没有指挥权，它能改的只有每个位置的两个代价，去不去仍由身体自己定，谁都不被它困住。这几条写成了方法一节的五条规则。读痕迹这一步没有变，变的是读到之后做什么。控制论建筑里早有主动的空间，Price 与 Frazer 的 Generator 会在没人动它的时候自己提出改法；这个项目从更保守的翻译者起步，被对照数据推回了那条谱系。旧规则留在实验 2-14 的台架上当对照档，规则一栏里的「痕迹」就是它，读者可以自己跑。

## 场景分类与选择

候选场景经筛选归纳为三类，每类对应一种人—动物关系，三类共同构成一条共同在场强度的梯度：

**人猫共享的室内（人—猫）：共居关系。** 猫是住户，人是来访者。这一类的公共版本是猫咖，仿真取的就是猫咖：猫与访客彼此陌生，共同在场短而反复，身体尺度差异显著，但共用同一批家具与同一片天花。

**宠物广场（人—狗）：中介关系。** 狗在该场景中的功能不是关系的对象方，而是人际交往的触发媒介。Goffman 所述的礼貌性忽视（civil inattention，陌生人之间默认互不注视的规范）在狗在场时被合法悬置；Whyte 将借助外部物件连接两名陌生人的机制称为三角化（triangulation）。该场景中空间需要处理的主要是被动物接通的人际关系。

**城市剩余空间（人—野生动物）：回避关系。** 双方主动规避共同在场，交互仅发生于痕迹层面（投喂点、通道、屋顶、废墟）。动物的活动范围随人类空间的收缩而扩张，反之亦然。

仿真先做第一类。场地选猫咖，因为只有它同时满足三件事：陌生人与住户动物反复同场，经营者本来就希望人和猫多互动，并且有人观察记录过里面的猫。三类用的是同一套循环（见「方法」节），先做人猫是因为它的数据最齐：猫对陌生人保持的距离有实测（Mertens 与 Turner，1988），猫在猫咖里选位置的规律有观察（Hirsch 等，2025），人对人的距离有跨国调查。第三类接着做平面上的对照，用城市鸟的惊飞距离作为动物的停留代价。第二类只在图版上呈现。

在第一类内部选猫而不是其他伴侣动物，依据有两条。人猫体型差异显著，尺度对比一眼可读。人猫关系中没有第三方中介，交互对象就是两个物种本身。猫的三维运动能力是第三条理由，但目前的平面仿真不建模高度，这一条要等立体单元接上行为层之后才成立。

三类场景均呈现于图版。仿真覆盖第一类的平面与立体，第三类做平面对照，第二类只在图版。

## 方法

仿真采用双层多智能体架构。**行为层**由人与猫两类身体智能体构成，其行为规则取自实证研究：人际距离规则取自 Hall 的近体学测量与一项跨国调查，陌生人交互规范取自 Goffman 的观察研究，停留行为的量化取自 Whyte 与 Gehl 的公共空间研究，猫的空间利用与人猫交互规则取自动物行为学文献（详见"行为条文"节）。规则分两档：阈值有实证出处的直接取用，没有出处的标为演示值，不冒充测量。**空间层**由天花悬挂的收缩单元构成，规则为本项目自拟。本阶段空间层只有一个动作：让某个单元落下成形，或者收回。合并、迁移、引诱、分裂、消融这几种操作是早先的设想，尚未实现，列在「尚未回答」一节。两层的写作标准刻意不对称，行为层受实证约束，空间层容纳推想。这种不对称构成本项目的方法论边界：推想被限定于单一层内，由实证层锚定。

仿真的时间尺度为分钟级，建模对象限于身体动力学变量：位置、朝向、停留时长、视线方向、运动路径。日或周尺度的出席决策（是否到场、停留意愿的长期变化）不纳入模型。

空间层按目的落单元。在人猫这一类里目的是促成相遇，落哪些单元按人的三种状态定。走着不触发，也不留痕迹。站定满三秒且看着一只猫，空间朝他给那只猫铺一步。坐下后，空间从最近一只猫脚下沿在场的单元一次只落一步，把猫引到座位前方一到一点五米那台。猫只读单元的状态，坐满三秒旁边有递过来的台，按自己的几率挪过去或者不挪。人走近一台落着的单元时，单元只收起朝他的那几条带，像开一道门，其余照落。早先那条「单元读脚下的痕迹，读满就落、退了就收」的规则留在台架上当对照档。空间只改每个位置的代价，不指挥任何个体。这一立场写成五条规则：空间层的输出只有每个单元的状态，不写任何个体的位置或目标。个体从空间读到的只有两个数，这里过不过得去，这里待不待得住。去哪里仍由个体按自己的行为规则决定。空间有没有达到目的只按结果算，用四类相遇事件计数。任何时候，任何个体从所在位置到出口都至少有一条走得通的路，会切断这条路的单元就不落。早先设想的效用函数框架（每个构件各算一个效用，目标可以互斥）没有实现，列在「尚未回答」。

两种代价来自早先的设计。通行代价由身体尺度与空间形式决定：落下的单元对人是一堵墙，只能绕行，对猫不是障碍，猫从下面过。停留代价由此刻身边有谁决定，每一拍重算：身边的人进到与关系相应的距离以内，代价就上升，高过阈值就离开。两条代价合起来给出一条不对称：猫能去人能去的所有地方，还能去更多，但不愿久留。人受体量限制，一旦进入就能稳定占据。仿真跑出来要能看到这条不对称，这是第一个验收。

构件的输入是行为痕迹的累积与衰减。痕迹随使用加深、随闲置消退，构成空间层与行为层之间唯一的信息通道。由此产生本项目关注的核心现象，即滞后（hysteresis）：构件因痕迹而改变形态后，不随身体离场即时复原，因为痕迹褪得比身体离场慢。猫正站在上面的单元还会被钉住，猫不走它就不收。滞后因此来自痕迹层和占用，不来自结构本身。结构是可逆的：扣合的键可以松开，一条布回直之后能再成另一种形。松键的探针证实了这一点，一条带成形、回直、再按另一张键谱成形，与一条全新的带逐位相同，布本身没有记忆。 [→ 日志 2026-10-06](/archive#log-2026-10-06-1)

三类关系共用一套循环，各自只换场地、目的与记账：

| | 人猫（共居） | 人狗（中介） | 人与野生动物（回避） |
|---|---|---|---|
| 场地 | 猫咖 | 宠物广场 | 城市剩余空间（具体场地待定） |
| 空间的目的 | 促成人猫相遇 | 分出人与人交流的一片和狗与狗玩的一片 | 动态划分：共处而不直接冲突，人仍得到体验 |
| 动物停留代价的依据 | 猫对陌生人的距离分布（Mertens 与 Turner，1988） | 待定 | 惊飞距离（城市鸟，文献） |
| 人的通行代价 | 落下的单元是墙 | 同左 | 同左 |
| 记账 | 四类相遇事件 | 同类相遇 | 看见与惊飞（候选） |
| 三类通用 | 循环、痕迹驱动单元、两种代价、五条规则、事件记账、天花悬挂单元 | | |

这个仿真探索的是手写规则的后果，不是对真实猫咖的预测。它能说的都是有条件的比较。如果访客保持文献里的陌生人距离、猫按 1988 年那次实验的距离分布行事，那么在同一套规则下，会动的空间与固定层架、空房间相比各得几分。秒数本身没有意义，有意义的只是条件之间的差，而且只在这套规则下成立。它擅长在建成之前找到规则之间的冲突，找到响应在什么条件下才值得，找到做不到的事。它做不到的是验证行为规则本身，那些是输入。要知道真实的猫会不会这样走，得去真实的猫咖看。

## 交互事件的形式化定义

本项目将全部交互结局归入四类形式化定义的事件，作为评估指标：

- **共视**：双方朝向同一视觉目标，允许存在高度差；
- **共温**：一方进入另一方 0.5–1.5m 舒适带并停留，无身体接触；
- **共触**：发生身体接触，为共温的升级态；
- **交接**：一方的运动路径穿越另一方的身体域。

此外定义**空事件**：信号发出而未获响应。空事件不作为无效数据处理，而是空间层介入的触发条件：行为层的招引落空之处，就是空间层该动的地方。招引这个动作目前还不在人的行为预设里，这一条尚未实现。

## 行为条文与交互矩阵

行为层规则以编号条文形式组织：猫的条文编号 C1–C8，人的条文编号 H3–H4，每条对应一项实证研究结论。条文中进入仿真的是距离阈值，作为两种代价的参数，其余条文目前只在图版上。其中猫的高处回避规则（C3）取自 Hirsch 等（2025）对瑞典某猫咖 27 只家猫的行为观察：高客流时段，猫显著偏好垂直层架与隐蔽处。

条文归纳出交互矩阵的两轴。猫轴取三个状态，其划分依据为成猫条文自身的分岔逻辑：陌生关系态（C1/C6 管辖，首次接近存在潜伏期）、熟悉关系态（C2 管辖，在猫咖里来自店员与常客）、高处回避态（C3 管辖，局部人类密度超过阈值时触发）。人轴取三个行为：穿行（H3/H4 的速度与密度规则）、专注驻留（C4 定义的注意力状态）、主动招引（C5 定义的慢眨眼或视觉—语音双模态信号）。三个行为里，穿行与驻留已在平面台架上实现，招引还没有。C8 作为全局调制器不进入矩阵：其将个体划分为回避型与主动型两档，调节所有格子的转移概率与时间参数。

两轴交叉产生九个单元格，每格对应一条触发规则与一个主导事件。以三格为例说明矩阵的解释力。熟悉态×穿行：熟人路径进入猫 0.5m 范围，猫保持位置，完成一次交接；该格与陌生态×穿行构成同一几何、相反结局的对照，为"关系状态改变空间通行权"提供最小证据单元。高处回避态×穿行：猫居高处，人从下方通过，交互仅余跨高度差的共视；该格直接构成结构需求：若猫的栖点固定于 2m 以上，共视无法升级，单元把平台降到交叠带（0.4–1.2m，两物种身体高度的重合区间）里的能力即为此格提供的出路。

九格中唯有一格存在条文间的真实冲突：高处回避态×主动招引，C5 的接近拉力与 C3 的回避推力同时作用，原始条文未提供合成规则。这一格怎么合成还没有答案，见「尚未回答」。

## 空间本体

交互介质为天花。结构方案为收缩张紧单元：一条布带挂在天花下，中间一根芯。芯收缩时布出现富余，布上预先排好的键把富余扣合起来，键扣合的位置决定形态。一个单元只有一个收缩自由度 ℓ。四种典型形态来自四张键谱：袋、蘑菇挑台、直挑台、阶梯方箱（见下图）。单条带绕一根竖轴排成一圈，二十条带收缩后扣出一圈平台。环再排成场地，十六个环站成一间房（实验 2-5、2-8）。按实验 2-8 的真实尺度，平台下缘离地 1.08m，落在两个物种身体高度重合的 0.4–1.2m 带内。

单元是被动的，没有出力的杆件，形态由键谱与收缩量决定。终态是路径依赖的数值解：键按扣合顺序逐颗锁定，每一步的位置由上一步推出，没有闭合公式，但同样的输入每次得到同样的结果。结构方案的入选标准有四：单元化、可复现地求解、有数学模型或设计工具支撑、以研究方法论而非艺术作品形式发表。此前评估并排除的候选包括气动桁架类系统（刚性杆件几何与织物垂坠形态不符）、升降柱类系统（自地面起立，与天花作为交互介质的设定冲突），以及早先的被动网面—绞盘方案（网形由缆长场决定，已被收缩单元取代）。

本项目对结构做了一条假设：键是可控的扣件，哪几对扣合、何时松开由控制决定，布在芯上夹持的位置也随程序变。这与被动吸附的键不同。有了这条假设，一条布才能在词汇表内换形，松键收回也才成立。真机上这是待验证的部分。

本项目的研究贡献不在某一条规则，而在这个循环本身：身体留下痕迹，空间读痕迹改形态，形态改变每个位置的代价，身体换一条路走，再留下新的痕迹。收缩单元是为此自建的仪器，行为规则是有出处的输入。

## 对照结果

同一间房、同一批人和猫，换三种空间跑：会动的单元，钉死不动的单元（相当于固定层架），什么都没有的空房间。每场五分钟，三十二个种子取均值，客流分三档：三位访客一只猫，六位访客两只猫，十二位访客三只猫。读四个数：共温，人停在猫身边的秒数；共触，距离不到半米的秒数；猫安稳停留的秒数；访客绕行的米数。

会动的单元做到了这几件事。六位访客起，人停在猫身边的时间同时高于固定层架和空房间：六人两猫 861 秒，固定层架 735，空房间 704；十二人三猫 2603 秒，固定层架 1980，空房间 1998，效应量 d 约 1.8，置换检验 p 小于千分之一。人多了猫更想上台这一项没有实测，换三组参数这条结论都成立。三位访客时三档分不开，装置的用处要人多到一定程度才看得出来。

猫在两档装置上安稳停留的时间相近，都长于空房间。人少时会动的单元让访客绕的路最短，十二人时比固定层架多绕一些，仍少于空房间。

接触是猫自己的决定。把引导换成座位旁边那台、整条路一次落下，十二人时共触高于固定层架，449 秒对 337，与空房间持平或略少。两种引导各偏一边，座位前方那台抬的是共温，座位旁边那台抬的是共触，同一套引导只能偏一边，这是两个距离带互斥的直接结果。检验没有做多重比较校正，p 在百分之一到百分之五之间的差别当方向读。

## 技术实现

结构引擎的原型用 Python 与 NumPy 写成并已收口，站上的版本是 TypeScript 的逐行移植，守门测试把它与 Python 的结果逐位对照。形态计算用位置式动力学，即 Verlet 积分加约束投影，这是找形领域动力松弛法的现代写法，力密度法（Schek, 1974）是它的文献脉络。行为层（痕迹场、单元激活、人与猫的身体）用 TypeScript 写在同一个站里。平面仿真把空间表示为网格，每个单元带一个成形程度。立体仿真用真实的带几何。平面台架里的 6×6 与 8×8 网格是 4×4 真实单元的等比缩小，小尺寸的结构单元还没有验证过。五条规则与两种代价已经进了仿真（实验 2-14）：人和猫在同一间房里，单元按规则落下和收回，四类事件实时记账，对照研究用同一份代码离线跑。全部规则为人工撰写的可读条文，不依赖传感器、计算机视觉或硬件。可视化在网页内完成：平面用 SVG 与 canvas，立体用不带依赖的 WebGL。

## 六次转向

**从社会退缩到自己待过的空间（2026-06-22）。** 起点是一个关于集体退缩的社会机制，骨架完整，却越写越不像自己的。于是从亲历的空间重新出发，题目后来落到人和动物怎样共用一间房。这之后问题都从亲历的空间里长出来，不从理论往下推。 [→ 日志 2026-06-22](/archive#log-2026-06-22-1)

**从两个时钟到一个（2026-07-27）。** 原设计有快慢两钟，慢钟里藏着最漂亮的结果，出勤崩塌之后回不去。砍掉它，是因为对象是一间房里以分钟计的身体，不该让规则书为同一个故事背两套文献。剩下的是分钟级的身体动力学，空间永远慢身体一步。 [→ 日志 2026-07-27](/archive#log-2026-07-27-3)

**没数据就不编（2026-07-28 至 07-29）。** 想要的那个距离没人测过，就写成概率分布并标为推断。品种假设被数据否掉，幼猫因为跳不高而独立成一类，推翻了一条写好的成猫规则。证据分三级的做法从这里定下来。 [→ 日志 2026-07-28](/archive#log-2026-07-28-1) [→ 日志 2026-07-29](/archive#log-2026-07-29-1)

**从悬吊网到收缩成形的表皮（2026-08-04 至 08-17）。** 网面的连续面耦合太强，一处动全盘动。换成一条带、一个收缩自由度、键决定形状。单元化由此开始，形态预先写在皮上，一台引擎复用到全部结构台。 [→ 日志 2026-08-04](/archive#log-2026-08-04-2) [→ 日志 2026-08-17](/archive#log-2026-08-17-1)

**记忆从布搬到痕迹（2026-10-06）。** 原来靠键永久锁定来做记忆。松键探针证明布回直后再成形与全新单元逐位相同，布没有记忆。记忆于是只能从痕迹讲，痕迹褪得比人离场慢，猫站着的台不收。结构因此可逆，同一个单元下次能成另一种形。 [→ 日志 2026-10-06](/archive#log-2026-10-06-1)

**从只追认痕迹到有目的、不下命令（2026-10-04 至 10-07）。** 只追认痕迹的空间在人停在猫身边这一项上输给了固定层架。给空间一个方向，再用五条规则把它限制在改代价上。旧规则保留为对照档。 [→ 日志 2026-10-07](/archive#log-2026-10-07-3)

## 尚未回答

- **冲突格的合成规则。** 高处回避态×主动招引这一格，C5 的接近拉力与 C3 的回避推力同时作用。早先的方案是用 Miller（1944）的趋避冲突梯度模型与 Ydenberg 和 Dill（1986）的逃逸经济学，把结局定义为垂直轴上的一个平衡高度 z*，单元把平台降到 z* 处。这条合成规则没有数据支撑，C3 本身也还没有数据，暂不作为依据。
- **垂直维度。** 平面仿真不建模高度。猫上高处与平台降下来都要等立体单元接上行为层。
- **效用框架与五个动词。** 每个构件各算一个效用、目标可以互斥，以及合并、迁移、引诱、分裂、消融五种操作，都还是设想。
- **小尺寸的结构单元。** 平面上的 8×8 只是等比缩小，真做小单元要另走一轮。
- **真实猫咖里的观察。** 仿真里的每个结论都只在这套规则下成立。要检验它，需要在一家有固定层架的猫咖里加一块能动的平台，记同一套事件。这是另一条线上的研究。
- **隔离怎么定义。** 回避关系里的"不直接冲突"用什么量还没有定。现有的候选是：一段时间里人没有一次进到动物的惊飞距离以内，同时人还看得见动物。

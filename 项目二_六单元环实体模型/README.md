# 项目二 · 六单元环静态演示模型（P2-SKIN-RING6-01 v1，2026-10-29）

用实体表示 Lab 2-5 圆筒环收缩后的形态：六个一样的 P2-SKIN-01 v3 下凹槽单元竖着排成一圈，凹槽朝外翻成方箱，方箱上表面是挑台的台面，一圈六个台面读作环形平台。模型是静态的，不做收缩。

用户拍板（2026-10-29）：单元用下凹槽版 v3（不用圆拱版），形状由内侧定型肋撑住。

DXF 是 R12，只有闭合多段线和圆，1 单位 = 1 mm；SVG 画布单位 mm。两者都只含切穿的轮廓。

输入图纸原样存在 `项目二参考/实体样件图纸/`（P2-SKIN-01 v3 下凹槽、P2-SKIN-ARC-01 v1 圆拱，均为 2026-10-02/03 版）。

## 做法

- 单元沿用 v3：板 101 / 67.5 / 43 / 67.5 / 101 × 75，接缝 5，A 面连 H1 / H4，B 面连 H2 / H3，表皮分段不变。只在 C2 / C3 / C4 的中点加了两个 Ø2 线孔（表皮对应位置同样开孔）。材料由纸板换成 3 mm 木板，厚度不变。
- 折后形状按理想铰点推算：每道缝绕凹侧表面、缝宽中点转 90°。结果是挑出 75.5、箱外高 56、单元折后高 261。实物会差 1–2 mm，以定型肋为准。
- 定型肋 R（每个单元一片，132 × 263）：外缘贴单元 B 面，肋舌伸进方箱，三面各让表皮 0.5，前角倒角 4 让开内角的表皮鼓包。C2 / C3 / C4 各用一针线穿过肋孔拉在肋上。
- 六片肋用十字半槽插在两块六边形板 P 上（边心距 72，槽 3 × 28.5，肋上对应 28.5）。P 板边托住端板 C1 / C5，两道箍带 S（12 宽）在 P 板高度把六个单元的端板收在板边上。
- 肋比单元长 2 mm，肋的下缘落桌，单元悬空。

整体：外接圆 Ø314，正面到正面 305，总高 263，台面离桌 160.5。单元之间的缝在内表面处 8.1，往外变大。

## 重出

```bash
python3 scripts/skin-ring6/build.py 项目二_六单元环实体模型
```

需要 reportlab、numpy、Pillow，以及系统字体 `wqy-zenhei.ttc`。几何与参数都在 `scripts/skin-ring6/geom.py`；`build.py` 出图时会读回三份 DXF，核对零件数、孔数、越界和 4 mm 以上的零件间距，不过则报错。

插槽宽 `SLOT` 默认 3.0。先切槽宽试件 T（五条槽 2.8 / 2.9 / 3.0 / 3.1 / 3.2），用同批木板去插，选出不松不紧的那条后改 `SLOT` 重出两张木板文件。

## 表皮材料（图纸第 04 / 07 页）

形状由肋撑住，表皮不承担回弹，只需要能弯过接缝、能粘、没有味道。图纸按 1 mm 厚出，换别的 1 mm 片材尺寸不用改。

- 推荐 1 mm 食品级硅胶片（邵氏 40–50A）：几乎没有气味，外观手感最接近橡胶，可以激光切（不含氯，切口有白色粉末）。难粘，用中性硅酮胶，先做试样。
- 书皮布 / 装裱布：没有气味，剪刀或激光切，白乳胶粘，最省事，但没有弹性。
- 原来的橡胶片：含氯配方（氯丁 CR、PVC 类）不能激光切。
- 表皮零件全是 75 宽的矩形，可以手工裁：先划 75 宽长条（共约 4.7 m），再截断，Ø2 孔用打孔器。

以后做“拉一下就成形”的实验时，表皮需要弹性，那时硅胶仍然能用，布和 EVA 不行。

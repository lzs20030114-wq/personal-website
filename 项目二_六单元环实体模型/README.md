# 项目二 · 六单元环静态演示模型（P2-SKIN-RING6-01 v3，2026-10-29）

用实体表示 Lab 2-5 圆筒环收缩后的形态：六个一样的 P2-SKIN-01 v3 下凹槽单元竖着排成一圈，凹槽朝外翻成方箱，方箱上表面是挑台的台面，一圈六个台面读作环形平台。模型是静态的，不做收缩。

用户拍板（2026-10-29）：单元用下凹槽版 v3（不用圆拱版）。

## 形状靠什么定住

- **芯**：上下两块六边形板和六条托 R 十字插成一个架子。每个单元的端板 C1、C5 贴在托的直边和板边上，两道箍带从外面压住。两端距离被定成 261，带子平铺是 400，多出来的 139 只能朝外折出去。往哪边折由铰链在哪一面连着决定，也就是 v3 交错分段的用处。
- **托**：托 R 沿墙内侧立着，在箱子里伸出两小块。上面一个小三角托住台面 C2，下面一个小台阶贴住底面 C4，各点一点胶。墙定住以后台面一锁，整个箱子就定了。底面那一块是保险，免得表皮铰链软、底面自己往下耷拉。台面往下垮时是压在托上，靠托本身就挡住，胶只是不让它被碰得往上翘。

两小块都在靠墙的里角。箱子内腔进深 70.5、高 46，小三角伸出墙外 20、高 22，顶住台面 18.5。小台阶伸出墙外 13、高 6，贴住底面 11.5。两小块和表皮之间各留 0.5 胶缝。托比单元长 2，托当脚，单元悬空。

单元顺着径向推上去：墙在小三角上面、小台阶下面都断开，台面从小三角上面滑过，底面从小台阶下面滑过。

### v1 → v2 → v3（都在 2026-10-29）

- v1：每个单元背后一片定型肋，肋舌就是整个箱子内腔的形状。用户指出它等于一个模子，拍到会像造假。
- v2：拿掉肋，改用 Ø10 立杆 + 四块六边形板，加箱子里的两根斜线把箱子锁成直角。用户指出拉线不现实。
- v3：照用户的草图做一个小托。v1 的肋缩成沿墙的一条，只在靠墙的里角伸出两小块，不用线、不打孔。

## 尺寸

单元板长 101 / 67.5 / 43 / 67.5 / 101 × 75，接缝 5，A 面连 H1 / H4，B 面连 H2 / H3，与 v3 相同。材料由纸板换成 3 mm 木板，厚度不变，板与表皮都不打孔。折后形状按理想铰点推算（每道缝绕凹侧表面、缝宽中点转 90°），实物会差 1–2 mm，以台面压在小三角上、台面水平为准。

整体外接圆 Ø314，正面到正面 305，托高 263、单元 261，台面离桌 160.5，挑出 75.5，箱外高 56。单元之间的缝在内表面处 8.1，往外变大。

## 重出

```bash
python3 scripts/skin-ring6/build.py 项目二_六单元环实体模型
```

需要 reportlab、numpy、Pillow，以及系统字体 `wqy-zenhei.ttc`。几何与参数都在 `scripts/skin-ring6/geom.py`，`build.py` 出图时会读回三份 DXF，核对零件数、越界和 4 mm 以上的零件间距，不过则报错。

托与 P 板的槽宽 `SLOT` 默认 3.0。先切槽宽试件 T（2.8 / 2.9 / 3.0 / 3.1 / 3.2），拿要用的木板去插，选插得进、不晃的那条槽后改 `SLOT` 重出两张木板。

## 胶

托顶着的是箱内那层 B 表皮，所以托上的胶跟着表皮选：硅胶用中性硅酮胶，书皮布用白乳胶，橡胶用万能胶。装的时候先用纸胶带把墙临时贴在板边上，上了箍带撕掉，再从箱子侧面用牙签把胶送进两道 0.5 的缝里。

## 表皮材料（图纸第 04 / 07 页）

表皮不承担回弹，只需要能弯过接缝、能粘、没有味道。图纸按 1 mm 厚出，换别的 1 mm 片材尺寸不用改。

- 推荐 1 mm 食品级硅胶片（邵氏 40–50A）：几乎没有气味，外观手感最接近橡胶，可以激光切（不含氯，切口有白色粉末）。难粘，用中性硅酮胶，先做试样。
- 书皮布 / 装裱布：没有气味，剪刀或激光切，白乳胶粘，最省事，但没有弹性。
- 原来的橡胶片：含氯配方（氯丁 CR、PVC 类）不能激光切。
- 表皮零件全是 75 宽的矩形、不打孔，可以手工裁：先划 75 宽长条（共约 4.7 m），再截断。

以后做“拉一下就成形”的实验时，表皮需要弹性，那时硅胶仍然能用，布和 EVA 不行。

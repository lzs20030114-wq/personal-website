# 项目二 · 六单元环静态演示模型（P2-SKIN-RING6-01 v2，2026-10-29）

用实体表示 Lab 2-5 圆筒环收缩后的形态：六个一样的 P2-SKIN-01 v3 下凹槽单元竖着排成一圈，凹槽朝外翻成方箱，方箱上表面是挑台的台面，一圈六个台面读作环形平台。模型是静态的，不做收缩。

用户拍板（2026-10-29）：单元用下凹槽版 v3（不用圆拱版）。

## 形状靠什么定住

和 Lab 2-5 一样只靠两件事，箱子里面没有按形状切出来的零件。

- **芯**：中间一根 Ø10 立杆，套四块六边形板（离单元两端各 12 和 90）。每个单元的端板 C1、C5 贴在板边上，两端距离被定成 261，带子平铺是 400，多出来的 139 只能朝外折出去。往哪边折由铰链在哪一面连着决定，也就是 v3 交错分段的用处。C1 在 s = 90、C5 在 s = 171 那块板上各缝一针；最上、最下两块板由两道箍带把端板压在板边上。
- **键**：每个箱子里两根斜线（板宽 10 与 65 处），从台面靠墙一端拉到底面靠外一端，两孔之间长 69.1。台面、正面、底面三块板和墙铰在一起能歪成平行四边形，竖着拉的线和墙平行，歪了也不变长，拉不住；斜线在箱子往下垮时要变长，所以拉得住。另一方向的斜线 BD 预留了孔，箱子会往上翘才穿。

装配用的卡条 J（定四块板的间距）和直角卡板 G（拉紧斜线时托平台面）是工具，装好就拿走，不留在模型上。

### v1 → v2

v1（同日上午）每个单元背后一片定型肋，肋舌就是箱子内腔的形状。用户指出它等于一个模子，拍照拍到会读成形状刻在木头上、像造假。v2 拿掉肋与它的插槽，C3 上的线孔也随之取消，改用上面的芯 + 键；单元尺寸仍一个数不改。

## 尺寸

单元板长 101 / 67.5 / 43 / 67.5 / 101 × 75，接缝 5，A 面连 H1 / H4，B 面连 H2 / H3，与 v3 相同；材料由纸板换成 3 mm 木板，厚度不变。折后形状按理想铰点推算（每道缝绕凹侧表面、缝宽中点转 90°），实物会差 1–2 mm，以拉紧斜线后台面水平为准。

整体外接圆 Ø314，正面到正面 305，总高 261，台面离桌 158.5，挑出 75.5，箱外高 56。单元之间的缝在内表面处 8.1，往外变大。

## 重出

```bash
python3 scripts/skin-ring6/build.py 项目二_六单元环实体模型
```

需要 reportlab、numpy、Pillow，以及系统字体 `wqy-zenhei.ttc`。几何与参数都在 `scripts/skin-ring6/geom.py`；`build.py` 出图时会读回三份 DXF，核对零件数、孔数、越界和 4 mm 以上的零件间距，不过则报错。

P 板中心孔 `DOWEL_D` 默认 10.0。先切孔径试件 T（9.6 / 9.8 / 10.0 / 10.2 / 10.4），拿买到的立杆去插，选不松不紧的那个后改 `DOWEL_D` 重出木板 A。

## 表皮材料（图纸第 04 / 07 页）

表皮不承担回弹，只需要能弯过接缝、能粘、没有味道。图纸按 1 mm 厚出，换别的 1 mm 片材尺寸不用改。

- 推荐 1 mm 食品级硅胶片（邵氏 40–50A）：几乎没有气味，外观手感最接近橡胶，可以激光切（不含氯，切口有白色粉末）。难粘，用中性硅酮胶，先做试样。
- 书皮布 / 装裱布：没有气味，剪刀或激光切，白乳胶粘，最省事，但没有弹性。
- 原来的橡胶片：含氯配方（氯丁 CR、PVC 类）不能激光切。
- 表皮零件全是 75 宽的矩形，可以手工裁：先划 75 宽长条（共约 4.7 m），再截断，Ø2 孔用打孔器。

以后做“拉一下就成形”的实验时，表皮需要弹性，那时硅胶仍然能用，布和 EVA 不行。

## 当前阶段

**物理结构阶段已收口。** 结构系统为"收缩张紧外皮单元"：天花垂下的单元阵列，每单元一个收缩自由度 ℓ。四种目标形态（袋 / 蘑菇挑台 / 直挑台 / 方形阶梯挑台）全部在 2D 剖面模拟中实现并验收，滞回对照实验通过。下一阶段: 单元阵列化进房间剖面，对接 3×3 行为矩阵（矩阵定义见 Miro 板 uXjVH7gpg8w=）。

## 结构系统定义

三层机械: **芯**（收缩源，单自由度 ℓ）→ **皮**（软布，富余材料载体）→ **键位图**（皮上预埋吸附点，决定收缩时材料扣合成什么）。

皮沿弧长分为:
- **贴合段 (g)**: 钉在芯上，构成竖直主干
- **自由段 (f)**: 藏富余材料 + 键谱；收缩压缩其占用芯距 → 富余集中鼓出成形

一个单元 = 段落表。例: `[('g',50), ('f',66, bonds, panels), ('g',50)]`

## 键谱语法（完整版）

1. **键** `(i, j, rb)`: 皮上两点吸附配对，rb 为键静止长度（0=缝合，>0=定距）。**等长键优先**——方形来自"等长约束下富余被拉平"，不要用多级键长堆形态（已验证的教训）。
2. **拉链顺序**: 吸引全员同时；锁定按跨度从大到小（主干→端头）逐颗放行，防止端头先封口困住材料。收缩完成后(step>950)纪律解除，允许已就位的键越序锁定，排掉滞留气泡。
3. **吸引护栏**: 仅在 rb < dist < D_ACT 时吸引；键距小于键长不再收紧（否则封死端面）。
4. **锁定永久**: 键一旦锁定不解开——滞回的物理来源。可崩键（拉力超阈崩开）为**暂缓项**，勿实现。
5. **面板** `(a, b)`: 指定区段强制直化 + x 向找直（端面板条）。
6. **键生成刚度**: 皮本身软（BETA≈0.8 仅助有序折叠）；锁定梯身施加多尺度层直化 + 梯挡垂直化（键两端 x 对齐）+ 台面找平（上层 y 向均值，仅键数≥3 的链）。刚度是成键的结果，不是皮的属性。

## 引擎技术要点 (skin_sim_v7_final.py)

- 位置式动力学: Verlet 积分 + 约束投影（= 动力松弛的现代形式，衔接文献 Schek 1974 力密度 / dynamic relaxation）
- 每步迭代内约束顺序**不可乱**: 钉贴合段 → 拉伸 → 多尺度抗弯 → 锁定键距离+梯挡垂直化 → 层直化/找平 → 面板 → **拉链判定（必须在迭代末尾，用最终位置判定，否则后续操作把键位推出窗口导致永久停摆）** → 重钉贴合段
- 外压 PRESS（3D 皮环向刚度的 2D 等效外撑）随收缩结束衰减至 0（step 900→1100），否则气泡顶死拉链
- 关键参数: SEG=0.02, BETA=0.80, GRAV=-1.8, DAMP=0.90(准静态防抖), ITERS=55, D_LOCK=0.14, K_ATT=0.10, K_STR=1.0
- 渲染层与物理层分离: render_smooth(w=3, passes=1, 保角) 只用于绘图；GIF 帧间指数平滑。物理数据不做美化
- 调参直觉: 刚度与分辨率必须同步标定；折叠 = 抗弯 vs 键吸引的竞争；自由段节数 = 材料预算；键谱两端留 ≥4 节缓冲；出问题先写诊断脚本打印锁定状态，不要盲调参数

## 冻结决定（不重开）

1. 被动网+绞盘阵列淘汰: 连续面耦合过强；由离散垂直单元阵列替代
2. 收缩张紧机制: 唯一驱动叙事是"芯收缩→皮富余→键扣合"
3. 吸附有图案（键位是设计对象），非全域吸附
4. 滞回由永久键物理实现——对照实验已证: 无键单元完全可逆，成键单元锁定（hysteresis_loop.png 为核心证据图；去程曲线上的锯齿=键扣合瞬间）
5. 材料预算耦合: 收缩量决定富余总量，多形态竞争材料（阵列阶段对接行为层的分配决策）
6. 交互必须发生在交叠带 0.4–1.2m；不得退化为"更聪明的猫爬架"
7. 复合单元合法: 一根带可堆叠多个形态（v4 已验证袋+挑台共存）

# 决定性瞬间的线稿（项目二）

把「感知 → 理解 → 干预」的每一条规则画成一行静帧线稿，给案例页和 PDF 作品集用。规则与图注的字取自 `项目二_输入到输出的规则.md` §4、§5。

三步，站上页面不改：

1. `capture.mjs`：先起生产服务（`npm run build && npx next start -p 3100`），打开 `/lab#lab2-16-<场景键>`，用假时钟快进到某一秒，在 WebGL 这一层把这一帧画的三角形（世界坐标）与每次绘制的颜色抄下来。
   `node scripts/moments/capture.mjs <几何目录> <场景键> <秒> [秒 …]`
2. `line.py`：用交接图册的线稿渲染器（`scripts/handover/render.py` + `raster.c`，要先编出 `raster.so`，见 `scripts/handover/README.md`）找线，合成黑白线稿。同名 `.json` 写出排版要用的数据：平面小图的东西、投影（正轴测，是仿射的）、人 / 猫 / 每台单元的包围盒。
   `python scripts/moments/line.py --plate scripts/moments/rows/letting-agent.json <几何目录> <线稿目录>`（按图版里每格的 `geo` / `opt` 一次出完 26 格，约 1 分钟）；单出一格：`python scripts/moments/line.py <几何前缀> <out.png> '<json 选项>'`
3. `sheet.mjs`：按 `rows/letting-agent.json` 排成图版，并把每格的 `notes` 画成线稿上的记号。
   `node scripts/moments/sheet.mjs scripts/moments/rows/letting-agent.json <线稿目录> <out.png> [宽] [带记号的单格出到哪个目录]`

## 画法（2026-11-23 作者定）

- 全部黑白线稿，线细。
- 触发的人或猫 = 中灰底、黑线、脚下一圈；被调动的单元 = 黑线、浅灰底；让路时只标收回的带；本来要落、没落的台 = 虚线框；人注视猫 = 虚线。
- 画面只取到约 2.4 m 高（单元平时收在天花板下，不入画）；2×2 的场地按 3×3 的比例尺画。

## 图上的记号（2026-11-25 作者「减少文字，多加图上的引导和图形说明，不读字也能看懂每组图的目的」）

线稿上不写句子，只有记号和数。记号在 `sheet.mjs` 里用线稿的投影数据画（矢量，改记号不用重出线稿），同一套记号在每格的平面小图里再画一遍。

| 记号 | 意思 | `notes` 里的写法 |
|---|---|---|
| 单元旁的竖箭头 ▼ / ▲ | 落下 / 收回 | `{k:'down'｜'up', u:[行,列], side?, dx?, dy?, label?}`，或 `at: 点` |
| 台面两侧一对向外的箭头 | 成形 | `{k:'spread', u}` |
| 虚线框里的 ✕ | 本来要落、不落 | `{k:'x', at}`（虚线框是 line.py 的 `ghosts`） |
| 小圈 | 台角会碰到人的那一点 | `{k:'clash', at}` |
| 弧线 / 地面折线，带箭头 | 猫 / 人的移动：虚线 = 将要去，实线 = 已走过 | `{k:'hop', a, b, dash?}` · `{k:'walk', pts, dash?}` |
| 带数字的小圈 | 引猫的第几步 | `{k:'step', at, n}` |
| 小钟 + 数 | 时长 | `{k:'tag', at, label, clock:1}` |
| 两端带短横的线 + 数 | 高度 / 距离 | `{k:'dimh', u, label}` · `{k:'dim', a, b, label}` |

点的写法：`[行, 列, 离地几米]` · `'p0'` 人脚下 / `'p0e'` 眼 · `'c0'` 猫 / `'c0t'` 顶 / `'c0b'` 底 · `'u:行,列'` 那台的台面中心 · `'u:行,列@行,列'` 台面高度上的另一点 · `'gaze'` 视线中点。

配套的版式：版头 = 一句目的 + 记号图例 + 一张关系图（列 = 前提 / 行走 / 站着 / 坐着，各带一个小人图标与「落几台」的方块；行 = 不妨碍人 / 落下的台；节点 = 那一行「干预」格的平面小图；箭头 = 前提）。每格下面只留一行短说明；格与格之间一个箭头表示先后；平面小图放在画面左下角（正轴测的左下角总是空的；08 行内容靠左，放右下角）。11-23 定的「不画落下箭头」由这一条取代：箭头用细线、小箭头，和尺寸线一个粗细。

## 放大的平面图（2026-11-26 作者「步数、单元避让人、虚线框是不是压在人头上，这些在轴测里很难看准，平面图要放大、多担信息；不是所有的图都要这样」）

行里写 `plan: 'big'` 的（03 让路 · 04 台角 · 05 注视 · 07 头顶 · 08 引猫），线稿角上不放小图，平面图放大排在线稿下面（三格一行 190 px、四格一行 146 px），说明在它右边。01、02、06 讲的是竖向的动作，仍用角上的小图。放大的平面图按真实尺寸画，比小图多这些：

- 台面 0.69 m 见方，落着的填浅灰；人的身体 ⌀0.44 m、猫 ⌀0.2 m；右下角 1 m 比例尺。
- 没落的台（虚线框）与人的身体重叠的那一块涂黑（04 是台角蹭到人，07 是整个人在台下面）。
- 让路时收回的带画成台面朝那几个方位的缺口（方位由 `line.py` 从收回的带的位置算出，写在 `.json` 的 `retracted` 里）。
- 只画在平面上的记号：`{k:'cand', cells}` 候选 / 将要落的台（点线框）· `{k:'ring', at, r:[米…], label}` 距离圈（03 身边 0.37 m、08 相遇 1.0–1.5 m）· `{k:'step', at:[行,列], n, planOnly?}` 引猫的第几步写在那一格的角上。

带记号的单格另存时，放大的平面图单独一张 `NN-k-plan.png`。
